DAY 9: COLOR THEORY FUNDAMENTALS

Decode the color wheel, saturation, value, and build scientifically sound color schemes

The Color Wheel

Primary: Red, Yellow, Blue. Secondary: Green, Orange, Purple (combination of primaries). Tertiary: Six combinations between primary/secondary. Understand relationships. Harmony emerges from relationships, not isolated colors.

Color Properties

Hue: The color itself (red, blue, green). Saturation: Color intensity (vibrant to gray). Value: Lightness/darkness (bright to dark). These three dimensions create infinite combinations.

Color Harmony Schemes

Complementary: Opposite colors (red + green). Maximum contrast. Use for emphasis. Analogous: Adjacent colors. Harmonious. Calming. Triadic: Three colors spaced equally. Vibrant. Balanced. Monochromatic: Single hue, varying saturation/value. Sophisticated. Professional.

HARMONY TIP: Start with monochromatic. Add accent color (complementary). This simple two-color system creates professional results while maintaining clarity.

Value Contrast

Light value on dark value creates highest contrast. Dark on dark creates no contrast. Medium on medium is muddy. Design with values first (grayscale). Then add color. If it works in grayscale, color will enhance it.

Mobile Color Considerations

Small screens amplify color. What looks acceptable on large monitor feels overwhelming on phone. Reduce saturation 20% for mobile. Increase value contrast to compensate. Test on actual devices. Colors render differently across screen technologies.

Saturation Strategy

Full saturation everywhere feels amateurish. Professional designs desaturate supporting colors. Let your primary brand color be saturated. Let supporting colors be 60-80% saturation. This creates visual hierarchy through color.
