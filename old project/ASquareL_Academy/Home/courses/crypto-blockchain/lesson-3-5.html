Lesson 3.5: Project - ERC20 Token Contract

Project Overview

Create a complete ERC20 token contract with transfer, approval, and minting capabilities.

Step 1: Set Up Development Environment

  • Install Node.js and npm
  • Set up Hardhat project
  • Configure testnet RPC endpoint
  • Get testnet ETH from faucet

Step 2: Implement ERC20 Standard

  • Implement transfer function
  • Implement approve and allowance
  • Implement transferFrom
  • Track balances and total supply

Step 3: Write Comprehensive Tests

  • Test transfer function
  • Test approval mechanism
  • Test minting/burning
  • Test edge cases and errors

Step 4: Deploy to Testnet

  • Write deployment script
  • Deploy to Goerli or Sepolia
  • Verify on Etherscan
  • Interact with contract

Project Requirements

  • ✓ ERC20 standard compliance
  • ✓ 18 decimals (standard)
  • ✓ Initial supply on deployment
  • ✓ Minting capability (owner only)
  • ✓ Burning capability
  • ✓ Full test coverage
  • ✓ Verified on Etherscan
Learning Objective: Understand token standards and deploy your first contract to a live network.

Deliverables

  • Contract source code (Solidity)
  • Test file with 100% coverage
  • Deployment script
  • Contract address on testnet
  • Etherscan verification link
  • Documentation of functionality
