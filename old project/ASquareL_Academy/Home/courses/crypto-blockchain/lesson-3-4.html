Lesson 3.4: Testing & Deployment

Testing Frameworks

  • Hardhat: Most popular, excellent developer experience
  • Truffle: Established framework with good documentation
  • Foundry: Fast, written in Rust
  • Test your contracts before deployment

Writing Unit Tests

  • Test happy paths and edge cases
  • Test access control and modifiers
  • Test event emissions
  • Test error conditions with expect revert

Deployment Process

  1. Test locally with Ganache or Hardhat
  2. Deploy to testnet (Goerli, Sepolia)
  3. Verify contract on Etherscan
  4. Test thoroughly on testnet
  5. Deploy to mainnet (production)
Never Rush: Take time to test thoroughly. Bugs in production cost real money.

Gas Optimization

  • Profile your contract for gas usage
  • Minimize storage operations
  • Use more efficient data types
  • Batch operations where possible

Common Deployment Issues

  • Insufficient gas limit
  • Constructor parameter errors
  • Address permissions (for upgradeable contracts)
  • Network mismatch
