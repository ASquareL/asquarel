Lesson 3.2: Solidity Fundamentals

Duration: 65 minutes | Difficulty: Intermediate

Solidity Syntax Basics

Solidity is statically typed and shares similarities with JavaScript and C++. Let's learn the fundamentals.

State Variables

Variables that persist on the blockchain, stored in contract state:

contract Counter {
    uint256 public count = 0;  // State variable
    address public owner;      // Address state variable
}

Data Types

  • uint: Unsigned integer (uint256 most common)
  • int: Signed integer
  • address: 20-byte Ethereum address
  • bool: Boolean true/false
  • bytes: Fixed-size byte arrays
  • string: Text data

Functions

Functions define contract behavior:

function increment() public {
    count = count + 1;
}

function getCount() public view returns (uint256) {
    return count;
}

Visibility Modifiers

  • public: Callable by anyone, can be called internally
  • private: Only callable within this contract
  • internal: Only callable by this contract and derived contracts
  • external: Only callable from outside the contract

Function Modifiers

Modifiers restrict function execution:

modifier onlyOwner() {
    require(msg.sender == owner, "Only owner");
    _;
}

function changeOwner(address newOwner) public onlyOwner {
    owner = newOwner;
}

Events and Logging

Events allow efficient logging of contract activity:

event Transfer(address indexed from, address indexed to, uint256 amount);

function sendFunds(address recipient, uint256 amount) public {
    // ... transfer logic ...
    emit Transfer(msg.sender, recipient, amount);
}

Control Flow

If/Else Statements

if (value > 100) {
    // Handle large value
} else if (value > 10) {
    // Handle medium value
} else {
    // Handle small value
}

Loops

for (uint i = 0; i < 10; i++) {
    // Loop body
}

while (condition) {
    // Loop body
}

Error Handling

  • require: Validates conditions, reverts if false
  • assert: Internal checks, always reverts if false
  • revert: Explicitly reject with error message
require(amount > 0, "Amount must be positive");
require(balance >= amount, "Insufficient balance");
assert(result == expectedValue);
Gas Efficiency: Every operation costs gas. Write efficient code: minimize storage writes, use local variables, avoid loops where possible.
