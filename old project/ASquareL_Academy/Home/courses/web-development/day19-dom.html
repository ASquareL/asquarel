📅 Week 7 - Day 1: The DOM

Duration: 3 hours | Focus: Bridging HTML and JavaScript

🎯 Learning Objectives

  • Understand what the Document Object Model (DOM) is.
  • Learn how JavaScript reads HTML as a structured "Tree".
  • Select specific HTML elements using JavaScript selectors.
  • Dynamically change text content and CSS styles using code.

🌐 What is the DOM?

When a web browser loads an HTML file, it translates that file into a massive JavaScript Object called the Document Object Model (DOM). This creates a "bridge." Because the HTML is now an object, JavaScript can reach into it, grab specific elements, and change them in real-time without refreshing the page.

🎯 Selecting Elements

Before you can change an element, you have to find it. JavaScript provides several built-in methods to target HTML elements.

1. Select by ID (The Old Way)

// Grabs the single element with id="main-title" const header = document.getElementById('main-title');

2. querySelector (The Modern Professional Way)

querySelector is incredibly powerful because it allows you to select elements using the exact same syntax you use in CSS.

// Select an ID (use #) const heroText = document.querySelector('#hero-text'); // Select a Class (use .) - This only grabs the FIRST one it finds const firstButton = document.querySelector('.btn-gold'); // Select an Element type const firstParagraph = document.querySelector('p');

✨ Manipulating the DOM

Once you have selected an element and saved it to a variable, you have total control over it.

Changing Text

const welcomeMessage = document.querySelector('#welcome'); // Change the text inside the element welcomeMessage.textContent = "Welcome to A Square L Innovate!";

Changing CSS Styles

const statusBox = document.querySelector('.status'); // You can change ANY CSS property. // Note: CSS properties with dashes (background-color) become camelCase in JS! statusBox.style.backgroundColor = "#D4AF37"; statusBox.style.color = "#000000"; statusBox.style.fontSize = "24px";

💻 Main Activity: Dynamic Styling

Task: The Status Updater

Create an index.html file with a single <div id="system-status">System Offline</div>.

Create an app.js file and write a script that does the following:

  • Selects the #system-status div.
  • Changes the text content to "System Online".
  • Changes the background color to green.
  • Changes the text color to white.
  • Adds a 20px padding.
