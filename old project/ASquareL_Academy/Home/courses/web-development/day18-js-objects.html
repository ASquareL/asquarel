📅 Week 6 - Day 3: Objects & JSON

Duration: 3 hours | Focus: Structuring Complex Data Models

🎯 Learning Objectives

  • Understand the difference between Arrays and Objects.
  • Create JavaScript Objects using Key-Value pairs.
  • Access and modify Object properties.
  • Understand JSON (JavaScript Object Notation) and how APIs work.
  • Combine Arrays and Objects for real-world data structures.

📦 What is a JavaScript Object?

While an Array is good for a simple list (like a grocery list), an Object is used for describing a single complex entity with specific properties. Objects use curly braces {} and organize data in Key-Value pairs.

// Example: A User Profile Object const userProfile = { firstName: "Ashiru", lastName: "Lawal", role: "Software Engineer", isAdmin: true, skills: ["HTML", "CSS", "JavaScript"] };

🔍 Accessing & Modifying Data

To grab a specific piece of data from an Object, we use Dot Notation.

// Reading data from the object console.log(userProfile.firstName); // Prints: "Ashiru" console.log(userProfile.skills[2]); // Prints: "JavaScript" // Modifying existing data userProfile.role = "Senior Engineer"; // Adding brand new properties on the fly userProfile.company = "A Square L";

🔗 Arrays of Objects (Real-World Architecture)

How Modern Databases Work

In professional apps, you almost never have just one object. You usually have an Array that contains hundreds of Objects (like an e-commerce store with hundreds of products).

const inventory = [ { id: 1, item: "Laptop", price: 1200 }, { id: 2, item: "Mouse", price: 45 }, { id: 3, item: "Keyboard", price: 80 } ]; // If we want the price of the Keyboard, we have to look in the Array at index 2, then ask for the 'price' property. console.log(inventory[2].price); // Prints: 80

🌐 What is JSON?

JSON stands for JavaScript Object Notation. When a frontend app (like React) needs to talk to a backend server (like Java or Python), they cannot send live JavaScript code over the internet. They must convert the Object into a text string first. This text format is called JSON.

// Convert a live JS Object into a JSON String (to send to a server) const jsonString = JSON.stringify(userProfile); // Convert a JSON String back into a live JS Object (when receiving data from an API) const liveObject = JSON.parse(jsonString);
