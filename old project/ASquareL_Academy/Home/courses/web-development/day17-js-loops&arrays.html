📦 Array Recap

Arrays are lists of data. When you look at an Instagram feed or a list of transactions in Moniepoint, you are looking at an Array of data being rendered to the screen.

const clients = ["Aliyu", "Sagiru", "Amina"]; // Arrays are zero-indexed! console.log(clients[0]); // "Aliyu" // Important Methods: clients.push("Khadija"); // Adds to the end of the array clients.pop(); // Removes the very last item console.log(clients.length); // Prints how many items exist

🔄 The For Loop

If you have 10,000 clients, you cannot write console.log() 10,000 times. We use Loops to tell the computer to repeat an action automatically.

A standard for loop has three critical parts inside the parenthesis:

  1. Start: Where does the counter begin? (usually let i = 0)
  2. Condition: When should the loop stop? (e.g., i < 5)
  3. Step: What happens after each cycle? (e.g., i++ to add 1)
// This will print "Hello" exactly 5 times. for (let i = 0; i < 5; i++) { console.log("Hello!"); }

⛓️ Looping Through Arrays

The Most Important Pattern in Web Dev

Combining an Array with a Loop is how 90% of web apps display data. We use the array's length as the stopping condition for the loop.

const cryptoAssets = ["Solana", "Bitcoin", "Ethereum", "Cardano"]; // i will be 0, then 1, then 2, then 3. for (let i = 0; i < cryptoAssets.length; i++) { console.log(`Checking price for ${cryptoAssets[i]}`); }
