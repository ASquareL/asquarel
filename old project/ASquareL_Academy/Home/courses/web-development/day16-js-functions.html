📅 Week 6 - Day 1: Functions & Scope

Duration: 3 hours | Focus: Reusable Code & Architecture

🎯 Learning Objectives

  • Understand the DRY principle (Don't Repeat Yourself).
  • Declare and invoke JavaScript functions.
  • Pass data into functions using Parameters and Arguments.
  • Output data from functions using Return statements.
  • Understand Local vs. Global Variable Scope.

⚙️ What is a Function?

A function is a reusable block of code designed to perform a single specific task. Instead of writing the same 10 lines of code every time a user clicks a "Buy" button, you write it once inside a function, and then "call" that function whenever you need it.

Declaring and Calling a Function

// 1. Declaring the function (Building the machine) function greetUser() { console.log("Welcome back to A Square L Academy!"); } // 2. Calling the function (Turning the machine on) greetUser(); greetUser(); // You can run it as many times as you want!

📥 Parameters and Arguments

Functions become powerful when they can accept dynamic data. We do this using parameters (the placeholders) and arguments (the actual data).

// 'firstName' is the Parameter (the placeholder) function sendEmail(firstName) { console.log(`Sending welcome email to ${firstName}...`); } // "Ashiru" and "Amina" are the Arguments (the real data) sendEmail("Ashiru"); sendEmail("Amina");

📤 The Return Statement

console.log() just prints text to the screen for developers to see. If you want a function to calculate a value and give it back to the program to be used later, you MUST use return.

function calculateTax(price) { const tax = price * 0.075; // 7.5% Tax return tax; // Hands the data back to the app } // We can save the returned data into a new variable! const laptopTax = calculateTax(1000); console.log(`The tax on the laptop is $${laptopTax}`);

🔒 Variable Scope (Global vs. Local)

The Vegas Rule of JavaScript

"What happens inside a function, stays inside the function." Variables created inside a function (Local Scope) cannot be accessed from outside.

const globalName = "CEO"; // Global Scope: Everyone can see this. function secureSystem() { const secretPassword = "12345"; // Local Scope: Trapped inside! console.log(globalName); // Works perfectly } console.log(secretPassword); // ERROR! The app crashes. It cannot see inside the function.
