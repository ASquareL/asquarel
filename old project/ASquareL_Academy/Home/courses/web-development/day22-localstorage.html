📅 Week 8 - Day 1: LocalStorage

Duration: 3 hours | Focus: Data Persistence & Browser Memory

🎯 Learning Objectives

  • Understand the concept of Data Persistence in modern web applications.
  • Save, retrieve, and delete data using the browser's localStorage API.
  • Combine JSON.stringify() with LocalStorage to save complex Arrays and Objects.

💾 The Refresh Problem

Think about a financial dashboard. When a business owner logs into their account, their transaction history is there. If they refresh the page, the data doesn't disappear. Up until now, all the JavaScript variables we have created are erased the moment the browser is refreshed. To build a real application, we must persist (save) the data.

Before we learn how to connect to massive external databases like Firebase or SQL, we start with the database built right into the user's browser: LocalStorage.

🛠️ The 3 Core Commands

LocalStorage acts like a digital filing cabinet. You save files (values) into folders (keys).

1. Saving Data (setItem)

// Syntax: localStorage.setItem('key', 'value'); localStorage.setItem('themeMode', 'dark'); localStorage.setItem('username', 'Ashiru');

2. Retrieving Data (getItem)

// To get the data back, ask for the specific key const savedName = localStorage.getItem('username'); console.log(`Welcome back, ${savedName}!`);

3. Deleting Data (removeItem)

// When a user logs out, you must clear their data localStorage.removeItem('username'); // Or, clear absolutely everything at once: localStorage.clear();

🧩 Storing Complex Data (The JSON Trick)

Crucial Limitation

LocalStorage can only store text strings. If you try to save a JavaScript Array or Object directly, the browser will break it. You must convert it to a JSON string first!

const userTasks = ["Learn DOM", "Build App", "Deploy"]; // ✅ CORRECT WAY TO SAVE: Convert to JSON String first localStorage.setItem('tasks', JSON.stringify(userTasks)); // ✅ CORRECT WAY TO RETRIEVE: Parse it back into a live Array const retrievedData = localStorage.getItem('tasks'); const liveArray = JSON.parse(retrievedData); console.log(liveArray[0]); // Prints: "Learn DOM"

💻 Main Activity: The Name Saver

Task: Persistent Greeting

Create an HTML file with a text input, a "Save Name" button, and an empty <h2 id="greeting"></h2> tag.

In your JavaScript:

  • When the page loads, check if a name exists in LocalStorage. If it does, update the h2 to say "Welcome back, [Name]".
  • Add an event listener to the button. When clicked, grab the value from the input, save it to LocalStorage, and update the h2 immediately.
  • Test it by typing your name, hitting save, and then refreshing the page! Your name should stay on the screen.
