Duration: 3 hours | Focus: Accessibility, Structure & Media Elements

🎯 Learning Objectives

  • Understand semantic HTML and its importance in modern web development

📚 What is Semantic HTML?

Semantic HTML uses tags that clearly describe their meaning to both the browser and the developer.

Benefits:

  • Improves accessibility for visually impaired users (screen readers)
  • Better SEO (Search Engine Optimization) so Google ranks you higher
  • Easier to read and maintain your code

Non-Semantic vs Semantic

Non-Semantic (The Old Way) Semantic (The Professional Way)
<div id="header"> <header>
<div id="nav"> <nav>
<div id="footer"> <footer>

🏗️ Semantic HTML Structure

<header> - Top section (logo, navigation)
<nav> - Navigation links
<main> - Main content area
<article> - Independent content
<section> - Thematic grouping
<aside> - Sidebar content
<footer> - Bottom section

Key Semantic Elements Explored

1. <header>

Contains introductory content, typically your logo, site title, and main navigation.

<header> <h1>My Website</h1> <nav> <a href="/">Home</a> <a href="/about">About</a> <a href="/contact">Contact</a> </nav> </header>

2. <nav>

Contains navigation links. Do not wrap all links in `nav`—only major navigation blocks.

3. <main>

The dominant content of the page. You should only use one `

` tag per page.

4. <article>

Self-contained, independent content (like a blog post, news article, or forum post).

<article> <h2>Article Title</h2> <p>Article content goes here...</p> </article>

5. <section>

A thematic grouping of content, typically with a heading.

6. <aside>

Side content, related to main content (like a sidebar, author bio, or callout boxes).

7. <footer>

Footer information at the bottom of the page or article (copyright, contact, social links).

🎵 Embedding Multimedia

Audio Element

<audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> Your browser does not support the audio element. </audio>

Key Attributes:

  • controls - Shows play/pause buttons (Mandatory so users can control it)
  • autoplay - Starts automatically
  • loop - Repeats continuously
  • muted - Starts muted

Video Element

<video width="640" height="360" controls> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> Your browser does not support the video tag. </video>

Embedding YouTube Videos

<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen> </iframe>
