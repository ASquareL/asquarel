📅 Week 5 - Day 2: Operators & Math

Duration: 3 hours | Focus: Processing Logic & Calculations

🎯 Learning Objectives

  • Master arithmetic operators for building calculators and algorithms.
  • Understand assignment operators to update variable values dynamically.
  • Learn strict comparison operators to check if data matches.
  • Utilize the built-in JavaScript Math object for complex calculations.

🧮 Arithmetic Operators

Computers are essentially just giant calculators. Arithmetic operators allow JavaScript to process numbers, which is essential for building things like shopping carts or trading dashboards.

// Example: Calculating profit from a Solana DEX trade const buyPrice = 120.50; const sellPrice = 145.00; const grossProfit = sellPrice - buyPrice; // Subtraction (-) const networkFee = grossProfit * 0.01; // Multiplication (*) const netProfit = grossProfit - networkFee; console.log(`Your Net Profit is: $${netProfit}`);

🔄 Assignment Operators

When building apps, you often need to update a variable's value based on its *current* value (like adding points to a score). You must use let for these variables, as const cannot be changed.

let userPoints = 100; // The long way: userPoints = userPoints + 50; // Now 150 // The professional, shorthand way (Addition Assignment): userPoints += 50; // Adds 50. Now 200. // Incrementing by exactly 1 (Very common in loops): userPoints++; // Now 201

⚖️ Comparison Operators

Comparison operators compare two values and ALWAYS return a Boolean (true or false). This is how apps make decisions.

Strict Equality vs Loose Equality

In JavaScript, never use ==. It is a loose check and can cause massive bugs (it thinks the number 5 and the string "5" are the same). Always use ===, which strictly checks that both the value AND the data type match.

console.log(10 > 5); // true (Greater than) console.log(10 <= 20); // true (Less than or equal to) // Equality Checks const databaseCode = 1234; const userInput = "1234"; console.log(databaseCode === userInput); // false (One is a Number, one is a String!) console.log(databaseCode !== userInput); // true (Strictly NOT equal)

🧠 The JavaScript Math Object

For complex calculations, JS has a built-in library called Math.

// Rounding a number console.log(Math.round(4.6)); // 5 console.log(Math.floor(4.9)); // 4 (Always rounds down to the floor) console.log(Math.ceil(4.1)); // 5 (Always rounds up to the ceiling) // Generating Random Numbers (Crucial for game dev or unique IDs) const randomDec = Math.random(); // Gives a random decimal between 0 and 0.99 const randomNum = Math.floor(Math.random() * 10) + 1; // Random whole number from 1 to 10
