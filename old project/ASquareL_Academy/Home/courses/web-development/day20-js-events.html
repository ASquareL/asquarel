📅 Week 7 - Day 2: Event Listeners

Duration: 3 hours | Focus: Making the DOM Interactive

🎯 Learning Objectives

  • Understand what JavaScript "Events" are.
  • Attach event listeners to buttons and inputs.
  • Trigger custom functions based on user interactions (clicks, hovers, typing).
  • Understand the powerful Event Object (e).

⚡ What is an Event?

If the DOM is the engine of your website, Events are the steering wheel and pedals. Every time a user clicks a mouse, types on a keyboard, scrolls the page, or resizes a window, the browser fires an "Event". We use JavaScript to "listen" for these events and execute code when they happen.

🎧 The addEventListener() Method

To make an element interactive, we attach an event listener to it. It requires two things: the type of event to listen for (like 'click'), and a function to run when it happens.

<!-- Your HTML File --> <button id="buy-btn">Buy Now</button>
// Your JS File // 1. Grab the element const buyButton = document.querySelector('#buy-btn'); // 2. Add the listener buyButton.addEventListener('click', function() { alert("Item added to your cart!"); buyButton.textContent = "Added! ✓"; buyButton.style.backgroundColor = "#10b981"; // Turn button green });

⌨️ Other Common Events

Clicks are great, but modern web apps track much more than that.

  • 'mouseenter' & 'mouseleave': Hover effects.
  • 'input': Fires every single time a key is pressed inside a text box.
  • 'submit': Fires when a user tries to submit a form.
// Example: Dynamic search bar matching Moniepoint's dashboard style const searchInput = document.querySelector('#search-box'); const displayArea = document.querySelector('#result-text'); searchInput.addEventListener('input', function() { // Update the text on the screen AS the user types! displayArea.textContent = `Searching for: ${searchInput.value}...`; });

🕵️ The Event Object (e)

Pro Developer Secret

Whenever an event fires, the browser automatically creates an "Event Object" packed with data about exactly what just happened (Where did the mouse click? Which specific key was pressed?). We capture this object by passing e or event into our function.

document.addEventListener('keydown', function(e) { if (e.key === "Escape") { console.log("User pressed the Escape key! Closing modal..."); } });

💻 Main Activity: Interactive VIP Pass

Task: Build a State-Toggling Button

Create an index.html file with a button that says "Follow".

Write an app.js script that does the following when the button is clicked:

  • If the button currently says "Follow", change the text to "Following" and change the background color to Gold.
  • If the button currently says "Following", change the text back to "Follow" and change the background to an outline.
  • Hint: Use an if/else statement inside your event listener to check the button's current textContent!
