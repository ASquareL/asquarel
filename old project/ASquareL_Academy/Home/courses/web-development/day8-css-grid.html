📐 What is CSS Grid?

Flexbox vs Grid: What is the difference?

Flexbox is a 1-Dimensional layout system. It aligns things in a single row OR a single column.

CSS Grid is a 2-Dimensional layout system. It handles both rows AND columns at the exact same time. It is perfect for complex page layouts, dashboards, and photo galleries.

🏗️ The Grid Container

Just like Flexbox, you start by applying a display rule to the parent container.

.grid-container { display: grid; grid-template-columns: 200px 200px 200px; /* Creates 3 columns, each 200px wide */ gap: 20px; /* Space between rows and columns */ }

The Magic "fr" Unit

Grid introduces a brand new unit called fr (fractional unit). It represents a fraction of the available space in the grid container. It is much better than percentages!

.grid-container { display: grid; grid-template-columns: 1fr 1fr 1fr; /* Creates 3 equal columns that stretch to fill the screen */ }

The repeat() Function

If you want 4 columns, writing 1fr 1fr 1fr 1fr is annoying. Use the repeat function instead!

.grid-container { display: grid; grid-template-columns: repeat(4, 1fr); /* Creates 4 equal columns */ }

🎯 Placing Specific Items

The true power of Grid is that you can tell a specific child element to span across multiple rows or columns.

/* Make an item stretch across 2 columns */ .featured-item { grid-column: span 2; } /* Make an item stretch down across 2 rows */ .tall-item { grid-row: span 2; }

💻 Main Activity: Build a Photo Gallery

Task: Create gallery.html

We are going to build a modern image gallery grid where some featured photos are larger than others.

HTML Structure

<section class="gallery-section"> <h2>My Portfolio Gallery</h2> <div class="grid-gallery"> <!-- Notice the special class on the first item --> <div class="gallery-item featured"><img src="img1.jpg"></div> <div class="gallery-item"><img src="img2.jpg"></div> <div class="gallery-item tall"><img src="img3.jpg"></div> <div class="gallery-item"><img src="img4.jpg"></div> <div class="gallery-item"><img src="img5.jpg"></div> </div> </section>

CSS Styling

/* Setup the Grid Container */ .grid-gallery { display: grid; grid-template-columns: repeat(3, 1fr); /* 3 Columns */ gap: 15px; } /* Make images fit the boxes perfectly */ .gallery-item img { width: 100%; height: 100%; object-fit: cover; /* Prevents images from stretching weirdly */ border-radius: 8px; } /* Advanced Spanning */ .featured { grid-column: span 2; /* Takes up 2 columns of space */ grid-row: span 2; /* Takes up 2 rows of space (Massive image!) */ } .tall { grid-row: span 2; /* Takes up 2 rows of space (Vertical portrait) */ }
