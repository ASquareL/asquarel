📚 Lecture Notes: How the Web Works

1. The Internet vs The World Wide Web

The Internet: A global network of interconnected computers that communicate using standardized protocols.

The World Wide Web (WWW): A system of interlinked documents and resources accessed via the Internet using web browsers.

Key Point: The Internet is the infrastructure; the Web is a service that runs on top of it.

3. What is HTTP?

HTTP (HyperText Transfer Protocol) is the foundation of data communication on the web.

HTTP Method Purpose Example
GET Retrieve data from server Loading a webpage
POST Send data to server Submitting a form
PUT Update existing data Editing a profile
DELETE Remove data Deleting an account

4. DNS: The Internet's Phone Book

DNS (Domain Name System) translates human-readable domain names into IP addresses.

Example: www.google.com → 142.250.190.46

Without DNS, we'd have to remember IP addresses for every website!

5. Key Web Technologies

  • HTML (HyperText Markup Language): Structure and content of web pages
  • CSS (Cascading Style Sheets): Styling and layout
  • JavaScript: Interactivity and dynamic behavior
  • HTTP/HTTPS: Communication protocol

🛠️ Setting Up Your Development Environment

Step 1: Install Visual Studio Code

📥 Installation Steps:

  1. Visit code.visualstudio.com
  2. Download the installer for your operating system
  3. Run the installer and follow the prompts
  4. Launch VS Code after installation

Step 2: Install Essential VS Code Extensions

Recommended Extensions:

  • Live Server: Launch a local development server with live reload (Crucial!)
  • Prettier: Code formatter to keep your code neat
  • Auto Rename Tag: Automatically rename paired HTML tags

How to Install: Click the Extensions icon on the left panel (Ctrl+Shift+X) → Search → Install

Step 3: Install Git

📥 Installation Steps:

  1. Visit git-scm.com
  2. Download Git for Windows/Mac
  3. Run installer with default settings
  4. Verify installation: Open VS Code Terminal and type: git --version

Purpose: Git tracks changes in your code and enables collaboration on GitHub.

Step 4: Create Your Project Folder

Desktop\web_basics\

images\

💡 Best Practice: Keep files organized in folders. Use lowercase names without spaces (use hyphens or underscores like my-page.html).

💻 Hands-On Activity: Your First HTML Page

Task: Create "Hello World" Webpage

Instructions:

  1. Open VS Code
  2. Click File → Open Folder and select your web_basics folder on your Desktop.
  3. Create a new file inside the folder and name it hello.html
  4. Type the code below exactly as it appears
  5. Save the file (Ctrl+S)
  6. To view it: Right-click inside your code editor and select "Open with Live Server"
<!-- HTML5 Document Type Declaration --> <!DOCTYPE html> <html lang="en"> <head> <!-- Character encoding for proper text display --> <meta charset="UTF-8"> <!-- Responsive design for mobile devices --> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Page title shown in browser tab --> <title>My First Web Page</title> </head> <body> <!-- Main heading --> <h1>Hello World!</h1> <!-- Paragraph content --> <p>Welcome to my first web page. My name is [Your Name].</p> <p>I am learning web development at A Square L Academy.</p> </body> </html>

Understanding the Code

  • <!DOCTYPE html>: Tells browser this is HTML5
  • <html>: Root element of the page
  • <head>: Contains meta information (not displayed)
  • <meta charset="UTF-8">: Character encoding for proper text display
  • <title>: Title shown in browser tab
  • <body>: Contains visible content
  • <h1>: Main heading (largest)
  • <p>: Paragraph

🎨 Try This: Modify Your Page

  • Change the heading text
  • Add your own name and information
  • Add more paragraphs with <p> tags
  • Save (Ctrl+S) and look at your browser—Live Server will update it instantly!
