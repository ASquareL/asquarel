🎨 What is CSS?

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation and design of your HTML documents.

CSS controls:

  • Colors and backgrounds
  • Fonts and text styling
  • Spacing (margins, padding)
  • Layout and positioning
  • Animations and transitions

Why Use CSS?

  • Separation of concerns: Keep content (HTML) separate from presentation (CSS)
  • Consistency: Apply the same styles across multiple pages
  • Maintainability: Change design without touching HTML
  • Efficiency: One CSS file can style an entire website

📝 CSS Syntax

selector { property: value; property: value; }

Example:

h1 { color: blue; font-size: 32px; text-align: center; }
  • Selector: What element to style (e.g., h1)
  • Property: What aspect to change (e.g., color)
  • Value: The specific setting (e.g., blue)

🔗 Three Ways to Add CSS

1. Inline CSS (Not Recommended)

Applied directly to an element using the `style` attribute.

<p style="color: red; font-size: 20px;">This is red text.</p>

⚠️ Avoid inline CSS - It is hard to maintain and mixes content with presentation.

2. Internal CSS (For Single Pages)

Written inside a <style> tag within the <head> section of your HTML.

<head> <style> body { background-color: #000; } h1 { color: #D4AF37; } </style> </head>

3. External CSS (Best Practice) ✅

Written in a separate `.css` file and linked to the HTML file.

<!-- In your index.html file --> <head> <link rel="stylesheet" href="css/style.css"> </head>
/* In your css/style.css file */ body { font-family: Arial, sans-serif; margin: 0; } h1 { color: #D4AF37; }

🎯 CSS Selectors

1. Element Selector

p { color: white; }

Selects all <p> elements on the page.

2. Class Selector (.)

.highlight { background-color: yellow; }
<p class="highlight">This paragraph is highlighted.</p>

3. ID Selector (#)

#header { background-color: #111; color: white; }
<div id="header">Header content</div>

💡 Classes vs IDs:

  • Use classes (.) for styling multiple elements.
  • Use IDs (#) for unique elements (only use an ID once per page).

4. Multiple Selectors

h1, h2, h3 { color: #D4AF37; font-family: Arial; }

5. Descendant Selector

article p { line-height: 1.6; }

Selects all <p> elements that live inside an <article>.

🎨 Common CSS Properties

Text Styling

Property Values Example
color red, #ff0000, rgb(255,0,0) color: #D4AF37;
font-size 16px, 1.5em, 100% font-size: 20px;
font-family Arial, serif, sans-serif font-family: Arial;
font-weight normal, bold, 700 font-weight: bold;
text-align left, center, right, justify text-align: center;
text-decoration underline, none, line-through text-decoration: none;

Background Properties

body { background-color: #000000; background-image: url('background.jpg'); background-size: cover; background-position: center; }

Colors in CSS

Named Colors: red

Hex Colors: #D4AF37

RGB: rgb(52, 152, 219)

RGBA (with transparency): rgba(52, 152, 219, 0.5)

Spacing: Margin and Padding

div { margin: 20px; /* Space OUTSIDE element */ padding: 15px; /* Space INSIDE element */ } /* Individual sides */ div { margin-top: 10px; margin-right: 20px; margin-bottom: 10px; margin-left: 20px; } /* Shorthand */ div { margin: 10px 20px; /* top/bottom left/right */ margin: 10px 20px 15px 25px; /* top right bottom left */ }

Borders

div { border: 2px solid #D4AF37; border-radius: 10px; /* Rounded corners */ } /* Individual properties */ div { border-width: 3px; border-style: dashed; border-color: #fff; }

🛠️ Chrome DevTools for CSS

How to Use DevTools:

  1. Right-click on any element on this webpage → Click "Inspect"
  2. Or press F12 or Ctrl+Shift+I
  3. Select the Elements tab
  4. View and edit CSS in real-time in the "Styles" panel on the right.

💡 Pro Tip: Changes in DevTools are temporary! If you refresh, they vanish. Always copy the changes back to your VS Code style.css file.

💻 Main Activity: Style Your News Page

Task: Create style.css and link it

Inside your web_basics folder, create a new folder named css. Inside that, create a file named style.css.

Step 1: Link CSS to HTML

Add this in the <head> of your `news-article.html`:

<link rel="stylesheet" href="css/style.css">

Step 2: Add this CSS to style.css

/* Reset default styles */ * { margin: 0; padding: 0; box-sizing: border-box; } /* Body styling */ body { font-family: 'Segoe UI', Arial, sans-serif; line-height: 1.6; color: #fff; background-color: #000; } /* Header styling */ header { background: #111; color: #D4AF37; padding: 20px; text-align: center; border-bottom: 2px solid #333; } /* Navigation */ nav { background-color: #1a1a1a; padding: 15px; } nav a { color: white; text-decoration: none; padding: 10px 20px; transition: 0.3s; } nav a:hover { color: #D4AF37; } /* Images */ figure img { width: 100%; border-radius: 8px; }

✏️ Practice Exercises

Exercise 1: Experiment with Colors

Change the following in your CSS:

  • Try different background colors for the header
  • Change the text colors using hex codes
  • Use `rgba()` for transparent effects

Exercise 2: Typography

  • Change font families (try: 'Georgia', 'Courier New', 'Times New Roman')
  • Adjust font sizes using `px` or `em`
  • Add `letter-spacing` and `line-height`

Exercise 3: Style Your Profile Page

Go back to `profile.html` from Week 1 and connect it to your new CSS file.

  • Style headings with colors
  • Add borders and padding to sections
  • Make your profile image circular using the code below:
/* Circular image */ img { border-radius: 50%; border: 3px solid #D4AF37; }
