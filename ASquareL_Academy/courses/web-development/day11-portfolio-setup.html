🏗️ Phase 3: The Architecture

Build out your index.html and style.css using the Flexbox and CSS Grid techniques we learned this week. Here is the core skeleton to get you started:

<!-- 1. Navbar (Flexbox) --> <nav class="navbar"> <h2 class="logo">DevPortfolio</h2> <ul class="nav-links"> <li><a href="#home">Home</a></li> <li><a href="#projects">Projects</a></li> </ul> </nav> <!-- 2. Hero Section (Flexbox Centered) --> <section id="home" class="hero"> <h1>Hi, I'm <span class="highlight">[Your Name]</span></h1> <p>A Frontend Developer trained at A Square L Academy.</p> </section> <!-- 3. Projects Section (CSS Grid) --> <section id="projects" class="projects-section"> <div class="grid-container"> <div class="project-card">Project 1</div> <div class="project-card">Project 2</div> <div class="project-card">Project 3</div> </div> </section>
/* The Ultimate Responsive Grid Code */ .grid-container { display: grid; grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); gap: 20px; } /* Smooth Scrolling for anchor links */ html { scroll-behavior: smooth; }

📄 Phase 4: Professional README.md

Recruiters look at your GitHub profile. A repository without a README.md looks unfinished. Use Markdown to create a beautiful introduction to your code.

# 🚀 Personal Portfolio Website ## 📌 Overview This is my personal portfolio website built to showcase my web development skills. Developed during my training at A Square L Academy. ## ✨ Features - 📱 Fully responsive design (Mobile-First) - 🎨 Modern UI with CSS Grid & Flexbox - 🎯 Smooth scrolling navigation ## 🛠️ Technologies Used - HTML5 (Semantic Structure) - CSS3 (Custom Variables, No Frameworks) - Git & GitHub ## 👤 Author **[Your Name]** - GitHub: [@yourusername](https://github.com/yourusername) - LinkedIn: [Your Name](https://linkedin.com/in/yourprofile)

🔍 Phase 5: Final Testing & QA

Functionality & Responsive Testing

Feature Test Case / Status
Navigation All menu links click and smooth-scroll to correct sections.
Images All images load without breaking the layout (No horizontal scrollbars).
Mobile (375px) Grid collapses to 1 column. Text is readable.
Tablet (768px) Grid expands to 2 columns. Spacing looks balanced.

W3C Validation

Professionals ensure their code has no syntax errors.

  • HTML: Paste your code at validator.w3.org and fix any red errors.
  • CSS: Paste your CSS at jigsaw.w3.org/css-validator to check for missing semicolons or brackets.

📊 Phase 6: Presentation Prep

You will present your portfolio to the class/mentor. Prepare a 3-minute walkthrough.

  • 1. Introduce Yourself: "Hi, I'm [Name], a Frontend Developer."
  • 2. The Walkthrough: Scroll through the site. Show how it adapts to mobile using DevTools.
  • 3. The Code: Highlight one piece of CSS you are particularly proud of (like your CSS Grid setup).
  • 4. The Challenge: Mention one bug you faced and how you fixed it.

✅ Today's Deliverable

Submit to your Mentor:

  • Your finished, fully responsive portfolio codebase.
  • Your populated README.md file.
  • Code pushed to the main branch of your GitHub repository.
