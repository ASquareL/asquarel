📝 Part 1: HTML Forms

What are HTML Forms?

Forms are used to collect user input. The data is typically sent to a server for processing.

Common uses: Login pages, registration, contact forms, search boxes, surveys

Basic Form Structure

<form action="/submit" method="POST"> <!-- Form elements go here --> </form>
  • action: Where to send form data (URL/file)
  • method: How to send data (GET or POST)

Common Form Elements

1. Text Input

<label for="name">Name:</label> <input type="text" id="name" name="name" required>

2. Email Input

<label for="email">Email:</label> <input type="email" id="email" name="email" required>

3. Password Input

<label for="password">Password:</label> <input type="password" id="password" name="password" required>

4. Radio Buttons (Choose One)

<p>Gender:</p> <input type="radio" id="male" name="gender" value="male"> <label for="male">Male</label> <input type="radio" id="female" name="gender" value="female"> <label for="female">Female</label>

5. Checkboxes (Choose Multiple)

<p>Skills:</p> <input type="checkbox" id="html" name="skills" value="html"> <label for="html">HTML</label> <input type="checkbox" id="css" name="skills" value="css"> <label for="css">CSS</label>

6. Dropdown (Select)

<label for="department">Department:</label> <select id="department" name="department"> <option value="">--Select--</option> <option value="cs">Computer Science</option> <option value="se">Software Engineering</option> </select>

7. Textarea (Multi-line Text)

<label for="message">Message:</label> <textarea id="message" name="message" rows="5" cols="50"></textarea>

8. Submit Button

<button type="submit">Submit Form</button>

📊 Part 2: HTML Tables

Table Structure

Tables display data in rows and columns.

  • <table> - Container for the table
  • <tr> - Table row
  • <th> - Table header (bold, centered)
  • <td> - Table data cell

Basic Table Example

<table border="1"> <tr> <th>Name</th> <th>Age</th> <th>Department</th> </tr> <tr> <td>Ahmad Tijjani</td> <td>22</td> <td>IT</td> </tr> </table>

🔧 Part 3: Git Version Control Basics

What is Git?

Git is a version control system that tracks changes in your code over time.

Benefits:

  • Track all changes to your files
  • Collaborate with other developers
  • Revert to previous versions if needed
  • Work on multiple features simultaneously (branches)

Git vs GitHub

Git GitHub
Version control software Web-based hosting service for Git repositories
Works locally on your computer Cloud-based platform
Free and open-source Freemium service

Essential Git Commands

1. Configure Git (First Time Only)

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

2. Initialize a Git Repository

git init

This creates a new Git repository in your current folder.

3. Check Status

git status

Shows which files have been modified, added, or deleted.

4. Stage Files (Add to Staging Area)

git add .

The dot (.) adds all changed files in the folder.

5. Commit Changes

git commit -m "Your commit message"

Saves a snapshot of your staged changes with a descriptive message.

6. Push to GitHub

git push -u origin main

Uploads your commits to GitHub.

Step 4: Push to GitHub using VS Code

In VS Code, press Ctrl + ` (Backtick) to open the Terminal. Then type:

git init
git add .
git commit -m "Initial commit: Added Forms and Tables"
git remote add origin https://github.com/yourusername/web-dev-basics.git
git branch -M main
git push -u origin main

💡 Pro Tips for Git:

  • Commit often with meaningful messages
  • Use present tense: "Add feature" not "Added feature"
  • Keep commits focused on one specific change
