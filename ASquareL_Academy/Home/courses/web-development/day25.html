📅 Week 9 - Day 25: Introduction to ES6+ Features

Duration: 3 hours | Focus: Modernizing Your JavaScript Syntax

🚀 The ES6 Revolution

In 2015, JavaScript received a massive update known as ES6. It fundamentally changed how we write code, making it cleaner, safer, and more scalable. As we step into Month 3, we are leaving old conventions behind and writing modern, enterprise-grade logic.

1. Let & Const (Block Scoping)

We no longer use var. Use const for variables that will never change, and let for variables that will be reassigned. This prevents massive bugs in larger codebases.

// ❌ THE OLD WAY var name = 'Ashiru'; // ✅ THE MODERN WAY const company = 'A Square L Innovate'; // Cannot be reassigned let terminalsDeployed = 120; // Can be updated later terminalsDeployed = 125; // This works perfectly

2. Arrow Functions

Arrow functions provide a shorter syntax for writing function expressions. They are essential when working with array methods and APIs.

// ❌ THE OLD WAY function calculateTotal(price, tax) { return price + tax; } // ✅ THE MODERN WAY const calculateTotal = (price, tax) => { return price + tax; } // 🔥 IMPLICIT RETURN (Even shorter for single-line logic) const getDiscount = price => price * 0.2;

3. Template Literals

Template literals eliminate the need for messy string concatenation. By using backticks (``) and the ${} syntax, you can inject variables directly into your text strings cleanly.

const user = 'Auwal'; const major = 'Computer Science'; // ❌ THE OLD WAY console.log('Welcome ' + user + ', your major is ' + major + '.'); // ✅ THE MODERN WAY console.log(`Welcome ${user}, your major is ${major}.`);
