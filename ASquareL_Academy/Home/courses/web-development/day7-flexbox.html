📦 What is Flexbox?

The Flexible Box Layout Module (Flexbox) makes it incredibly easy to design flexible responsive layout structures without using floats or positioning. It solves the biggest problem in CSS: Alignment.

The Golden Rule of Flexbox

Flexbox has two parts: The Parent (Container) and the Children (Items). You apply display: flex; to the Parent, and it magically controls how the children behave.

.parent-container { display: flex; }

🛠️ Flex Container Properties (The Parent)

1. flex-direction

Establishes the main axis (the direction the children line up).

flex-direction: row; /* Default: left to right */ flex-direction: column; /* Top to bottom */

2. justify-content (Horizontal Alignment)

Aligns items along the main axis (usually horizontally).

justify-content: flex-start; /* Default: pack to the left */ justify-content: center; /* Pack in the center */ justify-content: space-between; /* Distribute evenly, max space between */

3. align-items (Vertical Alignment)

Aligns items along the cross axis (usually vertically). Say goodbye to the nightmare of vertically centering a div!

align-items: stretch; /* Default: stretch to fill container height */ align-items: center; /* Perfectly center vertically */

Perfect Centering Hack

Combining justify-content: center; and align-items: center;

I am perfectly centered!

4. flex-wrap

By default, flex items will try to squeeze onto one line. flex-wrap tells them to wrap onto multiple lines if they run out of space.

flex-wrap: wrap;

💻 Main Activity: Build a Modern Navbar

Task: Create flex-navbar.html

We are going to use justify-content: space-between and align-items: center to build a professional navigation bar, exactly like the one at the top of this page!

HTML Structure

<header class="main-header"> <div class="logo">A Square L</div> <nav class="nav-links"> <a href="#">Home</a> <a href="#">About</a> <a href="#">Services</a> </nav> <a href="#" class="btn-contact">Contact Us</a> </header>

CSS Styling

/* The Flex Magic */ .main-header { display: flex; justify-content: space-between; /* Pushes logo left, btn right */ align-items: center; /* Vertically centers everything */ background-color: #111; padding: 20px 40px; } /* Flex the links too! */ .nav-links { display: flex; gap: 30px; /* Incredible property: puts exact space between flex items */ }
