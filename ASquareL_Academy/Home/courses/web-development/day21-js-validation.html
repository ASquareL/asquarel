📅 Week 7 - Day 3: Form Validation

Duration: 3 hours | Focus: Securing User Input

🎯 Learning Objectives

  • Understand the golden rule: Never trust user input.
  • Learn how to intercept a form submission using e.preventDefault().
  • Extract and evaluate values from input fields.
  • Dynamically display error messages in the DOM based on conditional logic.

🛡️ Why Validate Forms?

Data Integrity is Everything

If you are building a registration portal or a checkout system, you cannot allow users to submit empty fields, passwords that are too short, or text where a phone number should be. Validation ensures the data is clean before it ever reaches your database.

🛑 Stopping the Default Behavior

By default, when you click a "Submit" button inside an HTML form, the browser instantly refreshes the page and tries to send the data to a server. We have to stop this using JavaScript so we can check the data first.

const loginForm = document.querySelector('#login-form'); // We listen for the 'submit' event on the FORM, not the button! loginForm.addEventListener('submit', function(e) { // CRITICAL: This line stops the page from refreshing e.preventDefault(); console.log("Form intercepted! Now we check the data..."); });

🔍 Extracting the Input Values

Once we freeze the form, we need to grab what the user actually typed. We do this using the .value property.

loginForm.addEventListener('submit', function(e) { e.preventDefault(); // Select the input field, and immediately grab its value const emailInput = document.querySelector('#email').value; const passwordInput = document.querySelector('#password').value; // Checking if the fields are empty if (emailInput === "" || passwordInput === "") { alert("Please fill in all fields!"); } else { console.log("Data looks good. Ready to send to server."); } });

🎨 Displaying Professional Errors

alert() popups look unprofessional. A modern application injects the error message directly into the DOM right below the input field.

const errorDisplay = document.querySelector('#error-message'); // Inside your validation if-statement: if (passwordInput.length < 6) { errorDisplay.textContent = "Password must be at least 6 characters."; errorDisplay.style.color = "red"; }

💻 Main Activity: The Security Gate

Task: Build a Secure Registration Form

Create an index.html file with a form containing a Username input, a Password input, a Submit button, and an empty <p id="feedback"></p> tag.

Write an app.js script that intercepts the submission and runs these checks:

  • If the Username is empty, display "Username is required" in red text in the feedback tag.
  • If the Password is less than 8 characters, display "Password is too weak" in red text.
  • If both pass, display "Registration Successful!" in green text, and clear the input fields.
