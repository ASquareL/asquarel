📅 Week 8 - Day 2: Building the UI

Duration: 3 hours | Focus: Architecting the App Shell

🎯 Learning Objectives

  • Design the HTML structure for a dynamic Single Page Application (SPA).
  • Create dedicated DOM elements for inputs, triggers, and display areas.
  • Use CSS Flexbox to ensure the app looks professional and responsive on mobile devices.

🏗️ The App Architecture

Before JavaScript can do anything, it needs a "shell" to live inside. When building the UI for an application (like the Moniepoint dashboard or our Task Manager), you must think in three parts: The Input (Where user types), The Trigger (The button), and The Output (Where data is displayed).

The HTML Structure

Every dynamic app needs specific IDs so our JavaScript querySelector can easily find the elements.

<!-- The Application Container --> <div class="app-container"> <h2>A Square L Task Manager</h2> <!-- Input Area --> <div class="input-group"> <input type="text" id="taskInput" placeholder="Enter a new task..."> <button id="addTaskBtn">Add Task</button> </div> <!-- Output Area (Notice it is completely empty! JS will fill it later) --> <ul id="taskList"></ul> </div>

🎨 Styling the Application Shell

An application must look like an application, not a standard web page. We use CSS to lock the container size, remove default list styling, and use Flexbox to align the task text with the delete button.

/* The Main App Window */ .app-container { max-width: 500px; margin: 50px auto; padding: 30px; background: #111111; border: 1px solid #D4AF37; border-radius: 15px; } /* How a single task will look once JS adds it */ #taskList li { display: flex; justify-content: space-between; /* Pushes delete btn to the right */ align-items: center; padding: 15px; border-bottom: 1px solid #333; color: #fff; }

💻 Main Activity: Build the UI

Task: Construct Your App Shell

Today's task is purely structural. You are setting up the foundation for tomorrow's grand finale.

  1. Create a new folder called capstone_app.
  2. Create an index.html, a style.css, and an app.js file. Link them together.
  3. Write the HTML structure exactly as shown above, ensuring you use the exact IDs: taskInput, addTaskBtn, and taskList.
  4. Apply your CSS to make it look premium. Use the Black & Gold A Square L color palette. Ensure the input field and button look large and clickable on mobile devices.
