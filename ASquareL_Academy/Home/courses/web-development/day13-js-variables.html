🎯 Learning Objectives

  • Understand what JavaScript is and how it powers the web.
  • Master variable declaration using let and const.
  • Learn core JavaScript Data Types (Strings, Numbers, Booleans).
  • Create and manipulate Arrays (Lists of values).
  • Use console.log() to debug and test your code.

📝 Welcome to JavaScript

HTML creates the structure (the bones). CSS creates the design (the skin). JavaScript creates the logic and interactivity (the brain and muscles). It is the programming language that makes websites respond to user actions.

🔤 Variables: Storing Data

Variables are simply containers for storing data values in the computer's memory.

How to Declare Variables

// ❌ var - The old way (Avoid using this in modern code) var name = "Ashiru"; // ✅ let - The modern way (Use when the value WILL change later) let age = 25; age = 26; // Perfectly fine! The value was reassigned. // ✅ const - The modern way (Use when the value MUST NOT change) const country = "Nigeria"; // country = "USA"; // ERROR! The app will crash. Cannot reassign a const.

Best Practice Rule

Always use const by default. Only switch to let if you know absolutely for sure that the variable's value needs to change (like a score counter in a game).

📊 Data Types

1. String (Text)

Strings must always be wrapped in quotes.

const firstName = "Ahmad"; const lastName = 'Garba'; // String concatenation (The old way) const greeting = "Hello, " + firstName + "!"; // Template Literals (The modern, professional way - uses Backticks ` ) const message = `Welcome to the team, ${firstName} ${lastName}`;

2. Number

let age = 25; let price = 99.99; // Math operations let sum = 10 + 5; // 15 let product = 4 * 3; // 12 let remainder = 10 % 3; // 1 (Modulus - finds the remainder after division)

3. Boolean (True/False)

Booleans are the core of all application logic. They can only be true or false (no quotes!).

let isStudent = true; let hasGraduated = false;

4. Array (Lists of Data)

Arrays hold multiple values in a single variable. They are surrounded by square brackets [].

// Creating arrays const fruits = ["Apple", "Banana", "Orange"]; // Accessing array elements (CRITICAL: Computers start counting at 0, not 1!) console.log(fruits[0]); // Prints: Apple console.log(fruits[1]); // Prints: Banana // Finding how many items are in the array console.log(fruits.length); // Prints: 3 // Adding new elements to the END of the array fruits.push("Mango");

💻 Console.log() - The Developer's Best Friend

How do we know if our JavaScript is working? We print the results to the browser's hidden console. To see this, right-click on your webpage, click Inspect, and select the Console tab.

// Print simple text console.log("Hello, World! I am learning JS!"); // Print variables let playerName = "Sarah"; console.log(playerName);

🔗 Connecting JavaScript to HTML

Just like CSS, we need to link our JavaScript file to our HTML file so the browser knows to run the code.

<!DOCTYPE html> <html lang="en"> <head> <title>JS Practice</title> </head> <body> <h1>JavaScript Variables Practice</h1> <!-- CRITICAL: Place your script tag at the VERY BOTTOM of the body --> <script src="app.js"></script> </body> </html>
