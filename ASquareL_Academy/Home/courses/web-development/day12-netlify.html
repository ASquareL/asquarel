📅 Week 4 - Day 3: Launching to the World

Duration: 3 hours | Focus: Web Hosting, Netlify, and Continuous Deployment

🎯 Learning Objectives

  • Deploy your portfolio website to the internet using Netlify.

  • Customize your website's URL domain.

🌍 What is Deployment?

Right now, your website only exists on your laptop (and backed up on GitHub). If you send your index.html link to a client, they cannot see it. Deployment is the process of putting your code on a computer that is connected to the internet 24/7 so anyone in the world can visit it.

The Real Estate Analogy

Concept Web Development Equivalent
The House Your Code (HTML/CSS). You built it, painted it, and structured it.
The Plot of Land Web Hosting (Netlify, AWS, GoDaddy). You need to rent a space on the internet's "land" to place your house.
The Street Address The Domain Name (www.asquarel.com). People need a memorable address to find your house on that land.

🚀 Why Netlify? (The Magic of CI/CD)

In the old days, you had to manually upload files via FTP to a server every time you changed a single typo. Netlify changed the game by introducing Continuous Deployment (CI/CD).

  • Netlify connects directly to your GitHub repository.
  • When you run git push on your computer, GitHub tells Netlify, "Hey, there is new code!"
  • Netlify automatically rebuilds and updates your live website in seconds.
  • It is 100% free for static sites (HTML/CSS/JS).

💻 Main Activity: Deploy Your Portfolio

🛑 Pre-Flight Check!

Before we deploy, you MUST ensure that your main HTML file is named exactly index.html (all lowercase) and that it sits in the absolute root folder of your repository. If it is named Index.html or portfolio.html, the server will not find it!

Step-by-Step Deployment

  1. Go to Netlify.com and click Sign Up.
  2. Choose Sign up with GitHub. (This securely links your accounts).
  3. Once logged in, click the "Add new site" button, then select "Import an existing project".
  4. Click the GitHub button. You may need to authorize Netlify to view your repositories.
  5. Search for your my-portfolio repository and click on it.
  6. Site Settings: Leave the Build command and Publish directory completely blank. (Since we are just using plain HTML/CSS, no building is required).
  7. Click Deploy Site!

🎉 You are Live!

Netlify will generate a funny, random domain name for you (like brave-curie-72b81a.netlify.app). Click the link—your website is now live on the internet!

✏️ Customizing Your Domain

That random URL looks unprofessional. Let's change it to something clean.

  • In your Netlify Site Dashboard, click on Site settings.
  • Click Domain management.
  • Next to the funny name, click Options -> Edit site name.
  • Change it to something professional, like ashiru-portfolio.
  • Your new free domain is now: https://ashiru-portfolio.netlify.app!

✨ Activity: The Auto-Update Magic Trick

Let's prove that Continuous Deployment works.

# 1. Open your code in VS Code. Change a paragraph of text on your portfolio.

# 2. Save the file, then push it to GitHub:
$ git add .
$ git commit -m "Updated portfolio text"
$ git push origin main

# 3. Wait 15 seconds. Refresh your live Netlify website on your phone.
# The text updated automatically! No file uploads required.

🐛 Troubleshooting: "Page Not Found" (404 Error)

If you see a "Page Not Found" error on Netlify, it is almost always one of these two reasons:

  • Wrong Filename: Your file is named home.html or Index.html. Netlify servers specifically look for a file named exactly index.html (all lowercase) to act as the homepage.
  • Wrong Folder: Your index.html is trapped inside a sub-folder (like my-portfolio/src/index.html). Move it to the absolute root of the repository and push again.
