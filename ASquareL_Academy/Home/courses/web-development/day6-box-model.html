📦 The CSS Box Model

Every HTML element is essentially a rectangular box. The Box Model describes how the space around and inside that element is calculated by the browser.

MARGIN (Transparent, outside spacing)
BORDER (Visible edge)
PADDING (Space inside the border)
CONTENT (Text, Images, etc.)

Box Model Components Explained

  1. Content: The actual element data (text, images).
  2. Padding: The transparent space between the content and the border.
  3. Border: The line wrapped around the padding and content.
  4. Margin: The transparent space outside the border used to push elements away from each other.
div { width: 300px; /* Content width */ padding: 20px; /* Space inside */ border: 5px solid #D4AF37; /* Border */ margin: 10px; /* Space outside */ } /* Total width visually taken up by element: 300 + (20*2) + (5*2) = 350px */

📏 Margin (Outer Spacing)

Margin creates space outside an element's border, pushing other elements away.

/* All sides equally */ div { margin: 20px; } /* Individual sides manually */ div { margin-top: 10px; margin-right: 20px; margin-bottom: 30px; margin-left: 40px; } /* Shorthand - 4 values (Clockwise: Top, Right, Bottom, Left) */ div { margin: 10px 20px 30px 40px; } /* Shorthand - 2 values (Vertical Horizontal) */ div { margin: 10px 20px; /* 10px top/bottom, 20px left/right */ } /* CRITICAL: How to perfectly center a block element */ div { margin: 0 auto; width: 80%; }

🎨 Padding (Inner Spacing)

Padding creates space inside an element's border, pushing the content away from the edges.

/* Uses the exact same shorthand logic as margin */ div { padding: 15px; /* All sides */ padding: 10px 20px; /* vertical horizontal */ padding: 5px 10px 15px 20px; /* top right bottom left */ }

📐 Width, Height, and Box-Sizing

The Most Important CSS Rule You Will Learn Today:

By default, adding padding or borders to an element increases its total width. This breaks layouts! To fix this, developers universally use box-sizing: border-box;.

/* Apply this to EVERY project you build! */ * { box-sizing: border-box; }

🎭 Display Property

Block Elements (div, h1, p)

Take the full width available and start on a new line.

div { display: block; }

Inline Elements (span, a, strong)

Take only necessary width, flow horizontally, and ignore height/width declarations.

span { display: inline; }

Inline-Block

Flows horizontally like inline, but perfectly respects width, height, and padding declarations. Great for side-by-side elements.

.card { display: inline-block; }

💻 Main Activity: Build a 2-Column Layout

Task: Create profile-bio.html

Let's combine everything we've learned to build a page with a profile sidebar on the left and biography text on the right.

HTML Structure

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Profile Layout</title> <link rel="stylesheet" href="css/layout.css"> </head> <body> <header> <h1>My Professional Profile</h1> </header> <div class="container"> <!-- Left Column --> <div class="profile-column"> <img src="https://via.placeholder.com/200" alt="Profile"> <h2>Jane Doe</h2> <p>Frontend Developer</p> </div> <!-- Right Column --> <div class="bio-column"> <h2>About Me</h2> <p>I am a passionate web development student at A Square L Academy.</p> </div> </div> </body> </html>

CSS for 2-Column Layout (css/layout.css)

/* Universal Box-Sizing Reset */ * { margin: 0; padding: 0; box-sizing: border-box; } body { background-color: #000; color: #fff; font-family: Arial, sans-serif; } /* Flexbox makes column layouts incredibly easy */ .container { max-width: 1000px; margin: 40px auto; display: flex; gap: 30px; /* Creates space between the columns */ } /* Profile Column (Left - 30%) */ .profile-column { width: 30%; background: #111; padding: 30px; border: 1px solid #333; border-radius: 10px; text-align: center; } .profile-column img { width: 100%; border-radius: 50%; border: 3px solid #D4AF37; margin-bottom: 20px; } /* Bio Column (Right - 70%) */ .bio-column { width: 70%; background: #111; padding: 30px; border: 1px solid #333; border-radius: 10px; } /* Responsive Rule: Stack columns on phone screens */ @media (max-width: 768px) { .container { flex-direction: column; } .profile-column, .bio-column { width: 100%; } }
