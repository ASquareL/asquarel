📅 Week 5 - Day 3: Control Flow

Duration: 3 hours | Focus: If/Else Logic & Making Decisions

🎯 Learning Objectives

  • Understand Control Flow (how code makes decisions).
  • Write if, else, and else if statements.
  • Combine conditions using Logical Operators (AND, OR, NOT).
  • Build a security access checker script.

🧠 What is Control Flow?

By default, JavaScript reads your code from top to bottom, line by line. Control Flow allows you to hijack that process. You can tell the computer: "If this specific condition is true, run this block of code. Otherwise, skip it and run a different block of code."

The If Statement

The code inside the curly braces {} only executes if the condition inside the parenthesis () evaluates to true.

const userAge = 20; if (userAge >= 18) { console.log("Access Granted. You may enter the site."); }

🔀 If... Else

What if the condition is false? We use else to provide a backup plan.

// Example: Omniiera Dashboard Security Check const isSubscribed = false; if (isSubscribed === true) { console.log("Welcome to your Omniiera Dashboard."); } else { console.log("Please upgrade your plan to access this feature."); }

🚦 Else If (Multiple Conditions)

If you have more than two possible outcomes, chain them together using else if.

const batteryLevel = 15; if (batteryLevel > 50) { console.log("Battery is healthy."); } else if (batteryLevel > 20) { console.log("Battery is getting low."); } else { console.log("CRITICAL: Please plug in charger immediately!"); }

🔗 Logical Operators (AND, OR, NOT)

Sometimes a decision requires multiple things to be true at the same time. This is where Logical Operators come in.

  • AND (&&): BOTH sides must be true.
  • OR (||): ONLY ONE side needs to be true.
  • NOT (!): Flips the boolean (turns true to false).
const hasEmail = true; const hasPassword = true; // The AND Operator (&&) if (hasEmail && hasPassword) { console.log("Login successful!"); } // The OR Operator (||) const isWeekend = false; const isHoliday = true; if (isWeekend || isHoliday) { console.log("The academy is closed today."); }

💻 Main Activity: Grade Calculator

Task: Build an Exam Evaluator

Write a script that takes a variable called examScore (a number from 0 to 100). Use if/else if/else logic to log the following to the console:

  • If score is 90 or above: "A Grade"
  • If score is 80 to 89: "B Grade"
  • If score is 70 to 79: "C Grade"
  • If score is below 70: "Fail - Must Retake"
