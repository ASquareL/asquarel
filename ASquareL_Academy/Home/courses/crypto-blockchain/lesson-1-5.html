Lesson 1.5: Project - Blockchain Explorer

Duration: 90 minutes | Difficulty: Beginner

Project Overview

In this hands-on project, you'll use real blockchain explorers to analyze transactions, understand block structure, and explore how blockchain data is organized. Blockchain explorers are web applications that let you view all public blockchain data.

Learning Objective: Gain practical experience reading blockchain data and understanding how transactions flow through the network.

Tools You'll Use

  • Etherscan: Ethereum blockchain explorer (etherscan.io)
  • Bitcoin.com: Bitcoin blockchain explorer
  • Polygonscan: Polygon blockchain explorer

Project Steps

Step 1: Explore a Bitcoin Block

  • Visit bitcoin.com/explorer
  • Search for block #750,000
  • Note down the following:
    • Block hash
    • Block height
    • Timestamp
    • Number of transactions
    • Block size in bytes
    • Previous block hash
    • Miner's reward
  • Take a screenshot and save it

Step 2: Analyze a Bitcoin Transaction

  • In the same block, find a transaction
  • Click into the transaction to view details
  • Identify:
    • Transaction hash (TXID)
    • Number of inputs
    • Number of outputs
    • Total input amount
    • Total output amount
    • Transaction fee
    • Fee rate (satoshis per byte)
    • Confirmation count
  • Calculate: Total input - Total output = Transaction fee

Step 3: Explore Ethereum on Etherscan

  • Visit etherscan.io
  • Search for a recent block (search for "latest block")
  • Compare to Bitcoin block structure:
    • Block number (height)
    • Timestamp
    • Transactions
    • Block reward (base fee + tips)
    • Gas used vs gas limit
    • Miner/Validator
  • Note differences from Bitcoin (account model vs UTXO)

Step 4: Follow an Ethereum Transaction

  • Find a recent Ethereum transaction
  • Click into it and identify:
    • Transaction hash
    • From address
    • To address
    • Value transferred (in ETH and USD)
    • Gas limit
    • Gas price (in Gwei)
    • Transaction fee (total gas cost)
    • Block number
    • Number of confirmations
  • Calculate: Gas used × Gas price = Transaction fee

Step 5: Understand Gas in Ethereum

  • On Etherscan, find an active smart contract
  • Look at a contract interaction transaction
  • Note:
    • Higher gas usage than simple transfers
    • Gas price varies by network congestion
    • Transaction fee = Gas used × Gas price
  • Compare to a simple ETH transfer (21,000 gas)

Step 6: Investigate Address History

  • Search for a well-known address (e.g., Vitalik's address: 0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045)
  • Review the address overview:
    • Total transactions
    • Current balance
    • Token holdings
    • Transaction history
  • Click on a transaction to see full details

Step 7: Explore Token Transfers

  • On Etherscan, search for a popular token (e.g., USDC, USDT, DAI)
  • Review the token contract:
    • Contract address
    • Total supply
    • Number of holders
    • Transfer events
  • Compare token transfers to ETH transfers

Step 8: Create Your Analysis Report

Document your findings in a report that includes:

  • Screenshots of blocks and transactions explored
  • Key differences between Bitcoin and Ethereum
  • Explanation of fees and gas
  • Transaction examples with calculations
  • Observations about network activity

Key Concepts to Understand

Block Confirmation

  • Unconfirmed: Transaction in mempool
  • 1 confirmation: Block containing transaction
  • 6+ confirmations: Generally considered final
  • More confirmations = harder to reverse

Transaction Fees

  • Bitcoin: Calculated per byte (satoshis/byte)
  • Ethereum: Calculated per unit of computation (Gwei/gas)
  • Higher fee = faster inclusion
  • Network congestion increases fees

Address Privacy

  • All transactions are public and traceable
  • Addresses are pseudonymous (not anonymous)
  • Blockchain analysis can link addresses to identities
  • No deletion or modification of transactions

Reflection Questions

  1. What are the differences in block structure between Bitcoin and Ethereum?
  2. How does the transaction fee market work?
  3. Why are transaction fees important for network security?
  4. How would you estimate appropriate fees for different use cases?
  5. What does blockchain transparency mean for privacy?

Next Steps

After completing this project:

  • You can now read real blockchain data
  • You understand how transactions flow through networks
  • You can analyze fees and optimize transaction costs
  • Ready to dive deeper into smart contracts and DeFi
Pro Tip: Bookmark your favorite blockchain explorer. You'll use it constantly in your blockchain journey to verify contracts, check transactions, and research addresses.
