Lesson 3.1: Introduction to Smart Contracts

Duration: 50 minutes | Difficulty: Intermediate

What are Smart Contracts?

A smart contract is self-executing code stored on a blockchain. When conditions are met, the contract automatically executes without intermediaries.

Definition: Smart contracts are programs on the blockchain that execute automatically when predetermined conditions are met, eliminating the need for intermediaries.

Smart Contract Characteristics

  • Immutable: Once deployed, code cannot be changed
  • Deterministic: Same input always produces same output
  • Transparent: All code is visible on the blockchain
  • Autonomous: Executes without intermediaries
  • Irreversible: Executed transactions cannot be undone

Real-World Use Cases

Finance (DeFi)

  • Automated lending and borrowing protocols
  • Decentralized exchanges (swapping tokens)
  • Yield farming and staking
  • Insurance protocols

NFTs & Digital Assets

  • Digital art and collectibles
  • Gaming items and virtual worlds
  • Domain names and IP rights
  • Supply chain verification

Governance

  • Decentralized autonomous organizations (DAOs)
  • Community voting on proposals
  • Treasury management

Introduction to Solidity

Solidity is the primary programming language for Ethereum smart contracts. It's statically typed and designed for blockchain applications.

Why Solidity?

  • Purpose-built for smart contracts
  • Compiles to bytecode executable on EVM
  • Large developer community
  • Extensive libraries and tools
  • Well-documented and tested

Simple Solidity Example

Here's a basic "Hello World" contract:

pragma solidity ^0.8.0;

contract HelloWorld {
    string public message = "Hello, Blockchain!";
    
    function getMessage() public view returns (string memory) {
        return message;
    }
}

Ethereum Virtual Machine (EVM)

The EVM is the runtime environment for smart contracts on Ethereum.

Key Concepts

  • Bytecode: Compiled contract code
  • Gas: Cost to execute computations
  • State: Storage of contract data
  • Address: Location of contract on blockchain

Gas & Transaction Costs

Gas is the unit of computation cost on Ethereum. More complex operations cost more gas.

Gas Components

  • Gas Used: Amount of computation performed
  • Gas Price: Cost per unit (in Gwei)
  • Transaction Fee: Gas Used × Gas Price

Gas Optimization

  • Use local variables instead of storage when possible
  • Batch operations to reduce calls
  • Remove unnecessary computations
  • Use efficient data structures
Gas Matters: Always think about gas efficiency. Poorly written contracts waste user funds on expensive transactions.

Contract State & Transactions

State-Changing Functions

  • Modify contract data
  • Cost gas to execute
  • Create blockchain transactions
  • Example: transferring tokens

View/Pure Functions

  • Don't modify state
  • Free to call (no gas cost)
  • Read-only access
  • Example: checking balance

Security Considerations

Common Smart Contract Vulnerabilities

  • Reentrancy: Calling contract before state updates
  • Overflow/Underflow: Integer math errors
  • Front-running: Attackers seeing pending transactions
  • Unchecked External Calls: Assuming calls won't fail

Best Practices

  • Use established libraries and patterns
  • Get contracts audited before mainnet deployment
  • Test thoroughly on testnets first
  • Start with small amounts
  • Have emergency pause mechanisms

Development Tools

Popular IDEs & Frameworks

  • Remix: Browser-based IDE (great for beginners)
  • Hardhat: Ethereum development environment
  • Truffle: Development framework and testing suite
  • VS Code: Editor with Solidity plugins

Testing & Deployment

  • Ganache: Local blockchain for testing
  • Etherscan: Verify and publish contracts
  • Goerli/Sepolia: Ethereum testnets
  • Faucets: Get free test ETH

Your Learning Path

  1. Learn Solidity syntax and basics
  2. Write simple contracts
  3. Test on local network (Ganache)
  4. Deploy to testnet (Goerli)
  5. Interact with contract on testnet
  6. Verify code on Etherscan
  7. Eventually: Deploy to mainnet
Start Simple: Begin with basic contracts. Once you understand fundamentals, move to more complex patterns and optimizations.
