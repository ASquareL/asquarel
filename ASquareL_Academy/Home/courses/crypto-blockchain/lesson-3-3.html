Lesson 3.3: Advanced Solidity

Duration: 70 minutes | Difficulty: Intermediate-Advanced

Structs for Complex Data

Group related data together:

struct User {
    address addr;
    uint256 balance;
    bool active;
    string name;
}

User public user1 = User(msg.sender, 100, true, "Alice");

Mappings (Key-Value Storage)

Efficient key-value store for fast lookups:

mapping(address => uint256) public balances;
mapping(address => mapping(address => uint256)) public allowance;

balances[msg.sender] = 100;
uint256 myBalance = balances[msg.sender];

Arrays

Collections of same-type elements:

address[] public users;  // Dynamic array
uint256[10] public scores;  // Fixed-size array

users.push(msg.sender);
uint256 length = users.length;
address firstUser = users[0];

Inheritance

Inherit functionality from parent contracts:

contract Ownable {
    address public owner = msg.sender;
    modifier onlyOwner { require(msg.sender == owner); _; }
}

contract MyContract is Ownable {
    function specialFunction() public onlyOwner {
        // Only owner can call
    }
}

Interfaces

Define contract interfaces for interaction:

interface IERC20 {
    function transfer(address to, uint256 amount) external;
    function balanceOf(address account) external view returns (uint256);
}

contract MyToken is IERC20 {
    // Implement interface functions
}

Libraries

Reusable code without state:

library SafeMath {
    function add(uint256 a, uint256 b) internal pure returns (uint256) {
        return a + b;
    }
}

using SafeMath for uint256;
uint256 result = a.add(b);
Gas Optimization: Use libraries for common operations, be mindful of storage access (expensive), and optimize data structures for your use case.

Practice Project

Build a contract with:

  • Struct for user profiles
  • Mapping to store users
  • Array of active users
  • Modifier for access control
  • Events for tracking changes
