Welcome — What is the Web?

Welcome to Web Development. Over the next 52 lessons, you'll go from "I've never written code" to building real websites that work on phones, tablets, and desktops.

But before we write a single line of code, we need to answer a basic question: what actually is "the web"?

The web in one sentence

The web is a system of linked documents stored on computers called servers, which anyone with an internet connection can request and view using a program called a browser.

That's it. Everything else — apps, social media, online banking, this lesson you're reading — is built on that one simple idea: a document, on a server, viewed in a browser.

The three pieces

Every web experience involves three things working together:

  • The client — your browser (Chrome, Safari, Firefox). It asks for things and displays them.
  • The server — a computer somewhere in the world that stores websites and answers requests.
  • The network — the invisible infrastructure that carries messages between them.

When you typed the address of this page into your browser, the client sent a request across the network to a server, and the server sent back the page you're reading now. That whole round trip happens in under a second.

What you'll learn in this course

We've organized this track into six modules, each building on the last:

  • HTML — the structure of every page
  • CSS — how pages look
  • Layout & Responsive — how pages adapt to any screen
  • JavaScript — how pages become interactive
  • Advanced JavaScript — real apps that talk to servers
  • Modern Workflow — the tools professional developers use every day

By the end, you'll have 12 finished projects in your portfolio and a certificate that proves what you can do.

Your first habit

From today onward: type every code example by hand. Don't copy and paste. Your fingers learn patterns your brain doesn't notice yet. This single habit separates students who finish from students who don't.

Let's begin.
