# ASL Design System (ASLDS) Showcase

> **The official documentation website for the ASL Design System (ASLDS)** by **A Square L Innovate**.

The ASL Design System Showcase is the central documentation hub for ASLDS. It provides developers, designers, product teams, and contributors with comprehensive guidance for building consistent, scalable, accessible, and enterprise-ready user interfaces.

# Quick Start

Clone the repository:

```bash
git clone https://github.com/your-username/A-Square-L-Innovate.git
```

Navigate to the Showcase:

```text
packages/aslds/showcase/
```

Open:

```text
index.html
```

using your preferred browser or local development server.

# Accessibility

Accessibility is built into every aspect of ASLDS.

The Showcase promotes:

- Semantic HTML5
- Keyboard Navigation
- Screen Reader Compatibility
- ARIA Attributes
- Visible Focus States
- Responsive Layouts
- Readable Typography
- Accessible Color Contrast
- Reduced Motion Support
- Inclusive User Experiences

Accessibility is considered a default requirement rather than an optional enhancement.
