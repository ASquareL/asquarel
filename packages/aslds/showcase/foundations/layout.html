Layout

Build responsive layouts with the ASLDS layout system.

Every ASLDS application is built on a responsive layout foundation that combines flexible containers, grid systems, consistent spacing and mobile-first engineering principles. The layout system provides a predictable structure that scales seamlessly from small mobile devices to enterprise desktop dashboards.

Overview

Layout Philosophy

The ASLDS layout system establishes a consistent structure for every application. It encourages reusable patterns, predictable spacing and responsive behaviour while keeping implementation simple for developers.

12-Column Grid

Flexible layouts are built on a responsive twelve-column grid that adapts across all supported screen sizes.

Responsive Containers

Containers maintain readable content widths while preserving comfortable spacing on every device.

Flexbox Utilities

Utility helpers simplify alignment, distribution and ordering without custom CSS.

CSS Grid

Grid utilities make complex layouts responsive while reducing repetitive styling.

Consistent Spacing

Every layout follows the official spacing scale to create predictable visual rhythm.

Mobile-First

Components are designed for smaller screens first and progressively enhanced for larger viewports.

Engineering

Best Practices

Following these recommendations helps keep layouts maintainable, scalable and consistent across every ASLDS application.

Do

  • Use official containers.
  • Maintain consistent spacing.
  • Use semantic HTML layouts.
  • Prefer ASLDS utility classes.
  • Avoid deeply nested grids.

Don't

  • Mix Grid and Flex unnecessarily.
  • Hard-code spacing values.
  • Break responsive layouts.
  • Use fixed widths for pages.
  • Duplicate layout utilities.
Engineering Note

Build layouts from reusable foundations rather than page-specific CSS. This keeps every application visually consistent and greatly simplifies maintenance.
