Introduction

A Consistent Icon Language

Icons provide quick visual cues that improve navigation, clarify actions and reinforce meaning throughout user interfaces. The ASLDS icon system emphasizes consistency, accessibility and scalability, ensuring icons remain recognizable across every screen size and application.

Recognition

Familiar symbols help users understand actions without relying solely on text.

Consistency

Every icon follows the same visual style, spacing and sizing guidelines.

Accessibility

Icons complement interface labels and support assistive technologies when used appropriately.

Accessibility

Accessible Icon Usage

Decorative Icons

Decorative icons should use aria-hidden="true" so they are ignored by assistive technologies.

Meaningful Icons

Icons conveying important information should always include accessible text or labels.

Screen Readers

Never rely solely on icons to communicate meaning.

Labels

Pair every actionable icon with a visible or programmatic label.

Guidelines

Best Practices

Do

  • Use consistent icon sizes.
  • Maintain equal spacing.
  • Pair icons with text.
  • Reuse semantic colors.
  • Use official ASLDS icons.

Don't

  • Overload interfaces with icons.
  • Mix icon styles.
  • Use icons without context.
  • Depend only on color.
  • Use inconsistent sizing.
