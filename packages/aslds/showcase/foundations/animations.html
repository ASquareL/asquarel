Introduction

Motion Philosophy

Motion should communicate purpose, improve understanding and reinforce interaction. Every ASLDS animation is subtle, intentional and optimized for accessibility.

Meaningful Motion

Every animation should provide useful feedback instead of unnecessary visual decoration.

Performance

Hardware-accelerated transforms and opacity transitions are preferred for smooth rendering.

Accessibility

Motion always respects reduced-motion preferences and should never interfere with usability.

Consistency

Reuse the same timing, easing and motion patterns across every component.

Minimal Distraction

Motion should enhance the interface while allowing users to remain focused on content.

Principles

Motion Principles

Natural Movement

Animations should feel realistic and predictable.

Purposeful Feedback

Motion reinforces interaction outcomes.

Consistent Timing

Reuse standard durations across components.

Smooth Easing

Use predictable easing curves for continuity.

Performance First

Prefer transform and opacity for efficient rendering.

Motion Tokens

Duration Tokens

ASLDS standardizes animation durations to create predictable interactions across every component.

Instant

Variable: --duration-instant

Value: 0ms

Fast

Variable: --duration-fast

Value: 150ms

Normal

Variable: --duration-normal

Value: 250ms

Slow

Variable: --duration-slow

Value: 400ms

Extra Slow

Variable: --duration-extra-slow

Value: 600ms

Best Practices

Motion Guidelines

Do

  • Use subtle motion.
  • Keep durations consistent.
  • Animate with purpose.
  • Prioritize usability.
  • Maintain smooth transitions.

Don't

  • Animate everything.
  • Use distracting effects.
  • Create inconsistent timing.
  • Delay user interaction.
  • Ignore accessibility.
