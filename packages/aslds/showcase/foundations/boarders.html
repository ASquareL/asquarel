Foundation

Borders

Define structure, separation and visual consistency using the ASL Design System border foundation.

Borders are essential for grouping content, creating component boundaries and improving accessibility. ASLDS provides a consistent set of border widths, radius tokens, outline styles and semantic border colors to ensure every interface feels cohesive across products.

Introduction

Structure Through Borders

Borders help organize interfaces by separating content, defining interactive regions and improving readability. Combined with spacing, elevation and color, borders establish a clear visual hierarchy while maintaining accessible experiences across desktop and mobile interfaces.

Separation

Distinguish related content without unnecessary visual clutter.

Accessibility

Borders reinforce focus, grouping and interactive states alongside color and elevation.

Consistency

Reusable border tokens ensure every ASLDS application follows the same visual language.

Design Tokens

Border Width Tokens

Border widths establish consistent visual separation across every ASLDS component. Use these predefined tokens instead of arbitrary pixel values.

Recommendations

Best Practices

Do

  • Use official border tokens.
  • Maintain consistent corner radius.
  • Keep widths predictable.
  • Use borders to reinforce hierarchy.

Don't

  • Mix arbitrary border widths.
  • Overuse decorative borders.
  • Combine too many radius values.
  • Replace spacing with borders.
Developer Usage

Using Border Tokens

Always reference ASLDS design tokens instead of hardcoding border values. This keeps every application visually consistent and simplifies maintenance.

HTML Example 

<div class="card">
    ...
</div>

CSS Example 

.card{

    border:var(--border-thin)
           solid
           var(--border-color);

    border-radius:var(--radius-md);

}
