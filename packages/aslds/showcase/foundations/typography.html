Philosophy

Typography Philosophy

Typography is more than choosing a font. It establishes visual hierarchy, improves readability and creates a consistent user experience across every ASL application.

Clarity

Every text style is optimized for readability regardless of device size.

Consistency

Shared typography tokens create a predictable experience throughout the design system.

Accessibility

Proper font sizes, spacing and contrast improve readability for all users.

Readability

Reading Experience

ASLDS typography emphasizes comfortable reading through balanced line lengths, consistent spacing, logical hierarchy and carefully selected font weights. Long content remains easy to scan while interface text stays compact and informative.

Responsive

Responsive Typography

Typography scales naturally across desktop, tablet and mobile devices while preserving hierarchy, readability and comfortable line lengths.

Use responsive typography tokens instead of fixed pixel values whenever possible.
Accessibility

Accessibility Guidelines

Readability

Maintain comfortable line heights, appropriate spacing and sufficient font sizes for long-form content.

Contrast

Typography should always satisfy WCAG contrast recommendations against its background.

WCAG

WCAG Typography Recommendations

  • Use semantic heading hierarchy.
  • Never rely on color alone.
  • Maintain readable paragraph widths.
  • Avoid tiny text for essential content.
  • Ensure keyboard accessibility.
