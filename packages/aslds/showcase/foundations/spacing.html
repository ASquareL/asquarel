Foundation

Spacing

Consistent spacing creates professional, predictable and highly readable user interfaces across the entire A Square L Innovate ecosystem.

Every margin, padding, gap and layout spacing value in ASLDS is based on a unified spacing scale. Following this scale ensures visual rhythm, alignment, maintainability and responsive consistency throughout applications.

Philosophy

Why Spacing Matters

Spacing is one of the most influential foundations of interface design. Consistent spacing improves readability, reinforces hierarchy, reduces visual clutter and creates a polished user experience. Rather than using arbitrary values, ASLDS defines a structured spacing system that every component follows.

Visual Rhythm

Consistent spacing creates a natural flow that guides users through content without distraction.

Predictability

Designers and developers can build layouts faster when every spacing decision follows the same scale.

Maintainability

Reusing spacing tokens simplifies maintenance and keeps large projects visually consistent.

Rhythm

Consistent Vertical Rhythm

Every section, heading, paragraph, card, form and dashboard component uses the same spacing scale. This predictable rhythm makes interfaces easier to scan, improves reading speed and strengthens the professional appearance of the entire design system.

Never introduce arbitrary spacing values. Always build layouts using the official ASLDS spacing scale.
Scale

Official Spacing Scale

Every spacing value within ASLDS is based on reusable design tokens. Using the spacing scale keeps every component visually consistent and easier to maintain.

Token Variable Pixels REM Typical Usage
XS --space-xs 4px 0.25rem Icons, labels
SM --space-sm 8px 0.5rem Compact spacing
MD --space-md 16px 1rem Default component spacing
LG --space-lg 24px 1.5rem Cards & sections
XL --space-xl 32px 2rem Large layouts
2XL --space-2xl 48px 3rem Hero & page spacing

Best Practices

Recommended Spacing Guidelines

Following these recommendations helps teams build visually consistent, scalable and maintainable interfaces.

Use the Official Scale

Always use ASLDS spacing tokens instead of arbitrary values.

Prefer Gap

Use CSS Grid and Flex gap whenever possible instead of margins between sibling elements.

Maintain Rhythm

Keep vertical spacing predictable across sections, cards and forms.

Mistakes

Common Spacing Mistakes

Random Values

Avoid arbitrary spacing values that are not part of the official scale.

Nested Margins

Multiple stacked margins often create inconsistent layouts.

Mixed Units

Mixing pixels, rem, em and percentage values unnecessarily reduces consistency.

Uneven Padding

Components should use consistent internal spacing throughout the interface.

Engineering Notes

Developer Guidance

  • Build every layout using spacing tokens.
  • Never hard-code spacing values inside reusable components.
  • Use containers to maintain consistent page width.
  • Use responsive spacing rather than creating separate layouts.
  • Test spacing on desktop, tablet and mobile devices.
