Semantic Versioning

Understanding Release Numbers

ASLDS follows semantic versioning to make upgrades predictable and communicate the impact of each release.

Major

Introduces significant architectural changes or breaking updates.

Minor

Adds backward-compatible features and new capabilities.

Patch

Delivers bug fixes, performance improvements and maintenance updates.

Migration

Migration Notes

Most upgrades are designed to be backward-compatible. Review release notes before updating production applications and test custom extensions against the latest version.

Projects upgrading from v1.0 Stable to v1.1 Stable generally require no structural changes when following the documented framework conventions.
