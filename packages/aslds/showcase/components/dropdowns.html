Overview

Dropdown Overview

Dropdown components allow users to access related actions without overwhelming the interface, keeping navigation clean while supporting scalable enterprise workflows.

Compact

Present many actions inside a minimal UI.

Consistent

Unified dropdown behavior across all ASLDS products.

Accessible

Designed for keyboard navigation and assistive technologies.

Anatomy

Dropdown Anatomy

Every ASLDS dropdown follows a predictable structure to provide consistent interaction, accessibility and reusable navigation patterns.

Trigger

The button or control that opens the dropdown menu.

Dropdown Menu

Contains navigation links or contextual actions related to the trigger.

Menu Item

Represents an individual action or navigation destination.

Divider

Separates groups of related menu items for improved readability.

Accessibility

Keyboard navigation and ARIA attributes ensure inclusive interaction.

Placement

Dropdown Placement

Dropdown menus should automatically position themselves to remain visible inside the viewport while maintaining a consistent interaction pattern.

Bottom Start

Default placement for most dropdown menus.

Bottom End

Ideal for account menus and user actions.

Top Placement

Used when insufficient space exists below the trigger element.

Accessibility

Accessibility Guidelines

Dropdown components must remain fully accessible using keyboard navigation, semantic HTML and ARIA attributes.

Keyboard Navigation

Users should be able to open, navigate and close dropdown menus entirely using the keyboard.

ARIA Attributes

Apply appropriate ARIA roles, states and properties so assistive technologies can correctly interpret dropdown behavior.

Focus Management

Ensure focus moves predictably into the menu when opened and returns to the trigger when closed.

Clear Labels

Use descriptive trigger labels that clearly communicate the purpose of the dropdown.

Best Practices

Do & Don't

Do

  • Keep menu labels concise.
  • Group related actions together.
  • Support keyboard interaction.
  • Use clear menu hierarchies.
  • Maintain consistent placement.

Don't

  • Overload menus with too many options.
  • Hide essential navigation.
  • Use vague action labels.
  • Break keyboard navigation.
  • Create inconsistent menu layouts.
