Overview

Card Component

Cards organize related information into meaningful, reusable containers. They improve visual hierarchy, simplify scanning, and create consistent layouts throughout ASLDS applications.

Flexible

Supports simple content, media, actions, dashboards, forms and data presentation.

Consistent

Uses standardized spacing, borders, radius and shadows defined by the ASL Design System.

Responsive

Adapts naturally across desktop, tablet and mobile layouts without requiring custom implementations.

Accessible

Provides clear structure, semantic content grouping and predictable reading order for assistive technologies.

Accessibility

Accessible Card Design

Cards should remain understandable, keyboard accessible and easy to navigate for every user. Interactive cards should communicate focus, clickable regions and action hierarchy clearly.

Semantic Structure

Use appropriate heading levels and semantic elements to organize card content logically.

Keyboard Navigation

Interactive cards must remain fully operable using keyboard navigation and visible focus indicators.

Color Contrast

Maintain sufficient contrast between text, backgrounds, borders and interactive elements.

Screen Readers

Ensure card actions, links and controls expose meaningful accessible names.

Best Practices

Do & Don't

Do
  • Group related information together.
  • Use consistent spacing.
  • Provide clear titles.
  • Keep actions concise.
  • Maintain visual hierarchy.
Don't
  • Overload cards with content.
  • Mix unrelated actions.
  • Use inconsistent spacing.
  • Create unnecessary nesting.
  • Rely only on color for emphasis.
