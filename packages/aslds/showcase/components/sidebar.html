Sidebar

Build structured application navigation with the official ASL Design System Sidebar component.

The Sidebar component provides scalable, responsive and accessible navigation for dashboards, enterprise software, admin panels and documentation websites. It maintains consistent navigation patterns while supporting nested menus, responsive layouts and keyboard accessibility.

Overview

Sidebar Overview

Sidebars organize application navigation into clear, predictable sections. They help users quickly move between destinations while maintaining awareness of their current location within the interface.

Consistent Navigation

Use a stable navigation hierarchy across all pages to reduce cognitive load.

Responsive

Automatically adapts between desktop, tablet and mobile layouts.

Accessible

Supports keyboard navigation, focus visibility and screen readers.

Anatomy

Sidebar Anatomy

Every ASLDS sidebar is composed of reusable structural elements that provide predictable navigation and scalable application layouts.

Brand Area

Displays the application identity and provides quick access to the homepage.

Navigation Groups

Related destinations are grouped together for improved discoverability.

Navigation Items

Individual links provide access to pages, modules or application sections.

Active Indicator

Clearly identifies the user's current location within the application.

Footer Area

Commonly contains account information, settings and secondary actions.

States

Navigation States

Sidebar items communicate interaction through consistent visual feedback.

Default

Standard appearance for inactive navigation items.

Hover

Indicates the destination before selection.

Active

Highlights the current application section.

Disabled

Reserved for unavailable or restricted destinations.

Responsive

Responsive Behaviour

ASLDS sidebars automatically adapt to different viewport sizes while preserving usability, navigation hierarchy and accessibility.

Desktop

Persistent sidebar displayed alongside the application content for fast navigation.

Tablet

Sidebar may collapse into a compact layout while maintaining quick access to primary destinations.

Mobile

Hidden by default and revealed using the existing mobile navigation toggle for an optimized small-screen experience.

Accessibility

Accessibility Guidelines

Every ASLDS sidebar is designed to support keyboard users, assistive technologies and responsive navigation patterns.

Keyboard Navigation

All navigation links and controls must be reachable using the keyboard.

Focus Indicators

Maintain clear visible focus states for every interactive navigation element.

Screen Readers

Label navigation regions appropriately and provide meaningful link text.

Responsive Navigation

Ensure mobile sidebar menus remain fully accessible and dismissible using keyboard and touch controls.

Best Practices

Sidebar Best Practices

✓ Do

  • Keep navigation hierarchy simple.
  • Use descriptive labels.
  • Group related destinations.
  • Highlight the active page.
  • Maintain consistent ordering.

✕ Don't

  • Overload the sidebar with links.
  • Hide primary navigation.
  • Mix unrelated navigation groups.
  • Remove focus visibility.
  • Use inconsistent naming.
