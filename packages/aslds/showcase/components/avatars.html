Overview

Avatar Overview

Avatar components provide recognizable visual representations for users, teams and organizations while supporting profile images, initials and fallback states across ASL Design System applications.

Recognition

Help users quickly identify people and collaborators throughout the interface.

Consistency

Standard avatar styles create a unified identity system across every ASLDS product.

Accessibility

Avatar components support meaningful alternative text and accessible fallback content for every user.

Anatomy

Avatar Anatomy

Every ASLDS avatar follows a consistent structure to ensure recognizable identities and predictable behavior throughout every application.

Avatar Container

Defines the overall size, shape and visual boundary of the avatar component.

Profile Image

Displays the user's profile photograph when available.

Initials

Automatically provide a recognizable fallback when no profile image exists.

Status Indicator

Optional online, offline or busy indicators communicate current availability.

Accessibility

Accessibility

Accessibility Guidelines

Avatar components should always remain meaningful, accessible and understandable for every user, regardless of assistive technology.

Alternative Text

Every avatar image should include meaningful alt text describing the represented person or organization.

Initial Fallback

Display readable initials whenever profile images are unavailable to preserve user identity.

Color Independence

Never rely solely on avatar color to convey identity or status information.

Status Indicators

Presence indicators should complement accessible labels rather than replace them.

Best Practices

Do & Don't

Do

  • Provide meaningful alternative text.
  • Use initials as fallbacks.
  • Maintain consistent avatar sizes.
  • Show status indicators when appropriate.
  • Use avatar groups for teams.

Don't

  • Stretch profile images.
  • Depend only on colors.
  • Mix inconsistent avatar sizes.
  • Display decorative avatars without labels.
  • Overcrowd avatar groups.
