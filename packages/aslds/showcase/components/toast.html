Toasts

Deliver timely, accessible feedback with the official ASLDS Toast system.

Toast notifications provide non-intrusive feedback for user actions, system events, and alerts. The ASLDS Toast system supports multiple types, auto-dismiss, stacking, and full keyboard accessibility.

Overview

Toast Overview

Toast notifications are lightweight, time-sensitive messages that inform users of system events, confirmations, or warnings without interrupting their workflow.

Non-Intrusive

Toasts appear briefly and disappear automatically, keeping users focused on their current task.

Stackable

Multiple toasts can appear simultaneously without overlapping or causing confusion.

Accessible

Built with ARIA live regions for screen readers and keyboard-accessible dismiss buttons.

Types

Toast Types

Each toast type has a distinct visual style, icon, and semantic meaning to help users quickly understand the nature of the message.

Success

✓
Success!
Your changes have been saved.

Use for successful operations, completed tasks, and confirmations.

Error

✕
Error
Something went wrong. Please try again.

Use for errors, failures, and critical issues requiring user attention.

Warning

⚠
Warning
Your session will expire in 5 minutes.

Use for warnings, cautionary messages, and important notices.

Info

ℹ
Info
New update available. Click here to install.

Use for informational messages, updates, and neutral announcements.

Positions

Toast Positions

Toasts can be positioned in any corner of the viewport, adapting to your application's layout and user needs.

Top Right

Default position. Ideal for most applications and dashboards.

Top Left

Suitable for applications with right-aligned content or navigation.

Bottom Right

Recommended for chat applications or when toasts should not obscure top nav.

Bottom Left

Alternative for specific layout needs or user preferences.

Developer

JavaScript API

Use the ASLDS Toast API to programmatically display, dismiss, and configure toast notifications.

Basic Usage 

// Show a success toast
ASLDS.Toast.show({
    type: 'success',
    title: 'Success!',
    message: 'Your changes have been saved.',
    duration: 3000
});

// Show an error toast
ASLDS.Toast.show({
    type: 'error',
    title: 'Error',
    message: 'Something went wrong.'
});

Full Configuration 

ASLDS.Toast.show({
    type: 'success',     // 'success', 'error', 'warning', 'info'
    title: 'Success!',
    message: 'Your changes have been saved.',
    duration: 3500,      // milliseconds (0 = no auto-dismiss)
    position: 'top-right', // 'top-right', 'top-left', 'bottom-right', 'bottom-left'
    showProgress: true,
    showIcon: true,
    closeButton: true
});

Manage Toasts 

// Configure defaults
ASLDS.Toast.configure({
    duration: 4000,
    position: 'bottom-right',
    maxToasts: 5,
    pauseOnHover: true
});

// Clear all toasts
ASLDS.Toast.clear();

// Dismiss a specific toast
const toast = ASLDS.Toast.show({ ... });
ASLDS.Toast.dismiss(toast);
Best Practices

Do & Don't

✓ Do

  • Keep messages concise and actionable.
  • Use appropriate type for the message.
  • Set reasonable duration (3-5 seconds).
  • Provide a dismiss button for accessibility.
  • Use consistent positioning across the app.

✕ Don't

  • Use toasts for critical or urgent actions.
  • Overwhelm users with too many toasts.
  • Hide essential information in toasts.
  • Use toasts for long-form content.
  • Ignore accessibility guidelines.
