Accessibility

Accessibility Guidelines

Footer navigation should remain easy to understand, keyboard accessible and consistently organized across every ASLDS experience.

Semantic Structure

Use the semantic <footer> element so assistive technologies can correctly identify the page footer.

Clear Navigation

Group related links using headings and lists to improve navigation and content discovery.

Keyboard Support

Ensure every footer link is fully keyboard-accessible with visible focus indicators.

Link Labels

Use descriptive link text that clearly communicates each destination without relying on surrounding context.

Best Practices

Do & Don't

Do

  • Keep navigation well organized.
  • Use descriptive section headings.
  • Include legal information.
  • Maintain consistent branding.
  • Support keyboard navigation.

Don't

  • Duplicate primary navigation.
  • Hide important legal links.
  • Overcrowd the footer.
  • Use inconsistent layouts.
  • Break responsive behavior.
