Tabs

Organize related content into accessible, efficient and space-saving interfaces.

ASLDS Tabs enable users to switch between related sections without leaving the current page, providing clean navigation patterns for dashboards, settings, documentation and complex enterprise applications.

Overview

Tabs Overview

Tabs divide related information into logical sections while keeping interfaces organized, responsive and easy to navigate across every ASLDS application.

Organized

Present related information without overwhelming the user interface.

Efficient

Switch between content panels instantly without page navigation.

Accessible

Built with keyboard navigation and semantic interaction patterns for every user.

Anatomy

Tab Anatomy

Every ASLDS tab interface consists of predictable elements that provide consistent navigation, accessibility and reusable interaction patterns.

Tabs Container

Wraps the entire tab interface and manages the relationship between navigation and content panels.

Tab List

Contains the navigation items that allow users to switch between sections.

Tab Item

Represents an individual navigation option within the tab list.

Tab Panel

Displays the content associated with the selected tab.

Accessibility

Accessibility Guidelines

Tabs should support keyboard navigation, clear focus states and semantic relationships between tab buttons and their associated content panels.

Keyboard Navigation

Users should be able to navigate between tabs using the keyboard, including Arrow keys, Home and End where appropriate.

Focus Visibility

Always provide a visible focus indicator so keyboard users can identify the active tab.

ARIA Relationships

Associate each tab with its corresponding panel using appropriate ARIA roles, properties and identifiers.

Clear Labels

Use concise tab labels that accurately describe the associated content panel.

Best Practices

Do & Don't

Do

  • Group related content together.
  • Keep tab labels concise.
  • Support keyboard navigation.
  • Maintain a consistent tab order.
  • Display one active tab at a time.

Don't

  • Create excessive numbers of tabs.
  • Hide critical actions inside tabs.
  • Break focus management.
  • Use ambiguous labels.
  • Mix unrelated content.
