Anatomy

Progress Anatomy

Every ASLDS progress component follows a consistent structure that clearly communicates completion status while remaining simple and accessible.

Indicator

Label

Describes what the progress bar represents.

Percentage

Shows the current numeric completion value.

Status

Accessibility

Accessibility Guidelines

Progress indicators should remain understandable to all users through semantic markup, readable labels and assistive technology support.

Semantic Labels

Always provide descriptive labels so users understand what the progress indicator represents.

ARIA Support

Apply appropriate ARIA attributes, including role="progressbar" and descriptive values where applicable.

Color Independence

Never rely solely on color to communicate completion status. Pair color with labels and percentages.

Live Updates

When progress changes dynamically, ensure assistive technologies receive meaningful updates.

Best Practices

Do & Don't

Do

  • Display accurate progress values.
  • Provide descriptive labels.
  • Keep progress updates consistent.
  • Use semantic progress variants.
  • Maintain accessibility compliance.

Don't

  • Misrepresent completion status.
  • Depend only on color.
  • Animate excessively.
  • Hide progress from screen readers.
  • Use inconsistent progress scales.
