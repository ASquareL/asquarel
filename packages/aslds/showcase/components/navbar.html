Navbar Overview

Navigation is one of the most important interface elements. ASLDS Navbars provide a predictable, accessible and responsive experience that keeps users oriented throughout an application.

Provides identical navigation behaviour across every ASLDS product.

Responsive

Best Practices

Navigation Best Practices

Consistent navigation improves discoverability, usability and overall user confidence throughout every ASLDS application.

✓ Do

  • Keep primary navigation concise.
  • Highlight the current page.
  • Group related actions together.
  • Keep branding consistent.
  • Support keyboard navigation.

✕ Don't

  • Overcrowd the navigation bar.
  • Hide important destinations.
  • Use inconsistent labels.
  • Remove focus indicators.
  • Mix unrelated actions.
